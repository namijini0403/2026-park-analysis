# 지정·지원 명단 확보 백로그 (2026-09-06 조사)

`school_designations` 레이어에 넣고 싶었으나 **확보하지 못했거나 신뢰 가능하게 파싱하지 못한** 자료 목록입니다.
추측으로 학교 명단을 만들지 않는다는 원칙에 따라, 여기 적힌 항목은 산출물에 **전혀 반영되지 않았습니다**.
명단 미등재가 미지정 확정이 아니듯, 이 목록에 있는 사업의 학교별 상태는 앱에서 "자료 수집 전"입니다.

조사 경로(재현용): 인천광역시교육청 사전정보공표 색인
`https://www.ice.go.kr/ice/na/ntt/selectNttList.do?mi=11841&bbsId=2344&listCo=300` (292행)에서
사업별 게시판 `bbsId`를 찾고, 게시글 상세의 `DEXT5UPLOAD.AddUploadedFile(...)` 인자에서
`https://www.ice.go.kr/upload/ice/na/bbs_<bbsId>/<yyyy>/<mm>/<md5>.<ext>` 직접 다운로드 URL을 얻는다.

## C. 접근 방법상 막힌 것 (참고)

- `https://www.ice.go.kr/search/front_new/Search.jsp` 통합검색은 **JS/AJAX 전용**이라 정적 요청으로 결과를 얻을 수 없음.
  대신 사전정보공표 색인(`bbsId=2344`)이 서버 렌더링이라 더 나은 진입점.
- `selectAllNttList.do` 통합 게시판 검색은 `searchValue`를 **무시**함(서로 다른 검색어에 동일 바이트 응답).
  게시판별 `bbsId` 목록 조회로 대체해야 함.

## 갱신 주기 (재수집 시점)

교육복지우선지원 1~3월 · 다문화교육 4월 · 결대로자람 2월 · 자율학교 4월.
`bbsId`는 안정적이므로 각 게시판의 최신 `data-id`(=`nttSn`)와 첨부 경로만 다시 읽으면 재수집됩니다.
