‘최우수 학교’는 ‘녹지 환경 참고 학교’로 바꿨다. 공원 200m 이내 후보에서 녹지 분위 → 놀이터 유무 → 녹지비율 → 거리 순으로 비교하는 사례이며, 학교 종합평가가 아니다.

## 코드·정합성 수정

- 통계 생성기와 실제 앱의 참고 학교 정렬 우선순위가 달랐다. 생성기를 앱의 기존 기준에 맞췄다. 수정된 생성기로 만든 통계는 기존 통계 전체와 일치하며, 원래 참고 학교와 분류·수요 수치를 유지한다.
- 도보권 공원 수가 있으면 그 관측값을 사용한다. 수가 없을 때만 최근접 거리로 판단하며, 정확히 500m를 ‘500m 초과’로 취급하지 않는다.
- 후보 전환 시 AI 패널을 새 후보 기준으로 초기화하여 이전 답변이 남지 않게 했다. 연속 Enter 등 중복 요청과 한글 조합 중 제출도 방지했다.
- 전체 통계의 인쇄 제목에서 선택 학교명을 제거했다. 인쇄 버튼은 ‘펼친 내용 PDF/인쇄’로 범위를 명시한다.
- 학교 데이터 없이 직접 접근한 리포트·시뮬레이션은 예시 데이터임을 표시한다. 저장값이 배열·스칼라이면 학교 객체로 취급하지 않는다.
- 공통 상세 영역은 처음 펼칠 때 내용을 렌더링하고 이후 접어도 입력 상태를 유지한다. 키보드 초점·확장 상태·일부 선택 상태를 명시한다.

```powershell

npm --prefix ui-preview run build
```
