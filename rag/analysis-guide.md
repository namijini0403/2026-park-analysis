# 상세 분석의 설명 원본

화면에서는 분석 메뉴를 노출하지 않는다. 이 문서의 설명과 서버의 해당 학교·연도 자료를 묶어 한 챗봇에서 답한다. 과거 분석의 자동 추천 순위는 검색 대상에서 제외한다.

### [chunk: analysis#statistics] 상관관계·분포·학생 수 변화
tags: 상관, 관계, 관련, 보정, 통계, 분포, 지니, 추세, 변화, Sen, Moran
서버 계산 원본은 api/_analysis_engine.js이다. 상관관계는 순위상관 및 요청한 통제변수의 부분순위상관을 사용한다. 학생 수 추세는 모든 해당 연도를 공통으로 관측한 기관들의 합계와 연도 쌍별 기울기 중앙값(Sen)을 제시한다. 공통 관측이 없는 신설·폐원·결측 기관이 제외될 수 있다. 분포의 불평등과 지니는 정책적 바람직함을 자동 판정하는 기준이 아니다. 공간적 집중은 3km 이내 최대 8개 이웃으로 전역 Moran의 I를 계산하고 순열 검정과 국소 다중검정 보정을 사용한다. 분석마다 표본 수와 제외 범위를 함께 확인한다. 현재 환경 스냅샷과 연도별 공시를 결합하므로 과거 환경이 복원되었다고 말하지 않는다. 서버 계산에 필요한 변수나 관측이 없으면 결과를 만들지 않는다.

### [chunk: analysis#forecast] 학교 재학생 예측을 읽는 방법
tags: 미래, 예측, 전망, 수요, 학생수, LightGBM, Prophet, XGBoost, 성능, MAE, 학년
현재 재학생 모형 설명의 근거는 contest_plan/method_update_20260911.md 및 scripts/education/enrollment_model_v2.py다. 예측 원점까지의 자료로 잔차모형과 가중치를 선택하고 1·3·5년 선행을 따로 평가한다. 복잡한 보정은 추세보다 선택오차를 5% 이상 개선할 때 채택한다. 장기 이력이 부족하면 해당 선행기간 검증을 주장하지 않는다. 2025·2026 학년별 자료에 기초한 진급 시나리오는 최신 입학인원·진급비율 등을 유지하는 가정이며 독립 장기모형 교체의 증거가 아니다. 질문한 학교·연도에 실제 행이 있는 예측만 답한다. 모형명과 검증 지표는 해당 버전의 원자료로 확인하며 과거 R²를 최신 모델 성능으로 전용하지 않는다.

### [chunk: analysis#grid] 후보 격자와 미래 인구 시나리오
tags: 격자, 후보지, 수요, 인구, 시나리오, 250m, SHAP, 파레토
250m 격자는 조사 지점이지 설치 가능한 확정 부지가 아니다. 격자 내부 인구와 직선 500m 주변 인구는 서로 다른 범위다. 현재 미래 격자 자료는 도시 전체 연령인구 성장률을 균일 적용하는 시나리오이며 후보 위치별 미래 인구 분포를 검증한 예측이 아니다. 이전 수요모형 SHAP·안정성 결과는 새 수요에 재사용하지 않는다. 인구가 많아도 이용자격·경로·안전·실행 근거 미확인을 상쇄하지 못한다. 자료 원본: data_processed/education/candidate_demand_v2.json. 설명 원본: contest_plan/method_update_20260911.md.

### [chunk: analysis#routes] 경로 검수의 의미
tags: 도보, 경로, 출입구, 카카오, OSM, 단절, 우회, 안전, 도로
OSM 보행망 일괄 도달권과 점간 도보 경로 비교는 목적이 다르다. 대표점 사이의 거리 비교가 일치해도 출입구·개방시간·통행 허용·횡단 안전은 검증되지 않는다. 도로 유형별 경로 길이는 실제 횡단 횟수나 사고위험이 아니다. 경로 실패는 거리 0으로 기록하지 않는다. 주거 구역 내부 통행을 열어 추가 면적을 계산하는 결과는 가정 시나리오로 설명한다. 설명 원본: docs/walkshed_route_method_summary.md, contest_plan/method_update_20260911.md.

### [chunk: analysis#context] 주변 환경과 지정학교 정보
tags: 유흥, 공사, 재개발, 아파트, 대단지, 지정, 연구학교, 선도학교, 학원, 학구도
인허가 업소·공사장·정비사업·대단지·지정학교는 관측된 행정기록이다. 주변에 기록이 있다고 아동에게 위해가 발생했다거나 정책 효과가 있다고 단정하지 않는다. 지정학교의 위치 근접·가상 연결은 실제 교류나 확산 효과가 아니다. 학교급·지정연도·명칭의 일치 범위를 확인한다. 학구도와 대표점 포함을 실제 취학·입학 수요의 확정값으로 해석하지 않는다. 수집되지 않은 분야는 0이 아닌 미확보다. 학교별 관측 원본: data_processed/context/education_school_evidence.json.

### [chunk: analysis#similar] 유사학교 비교
tags: KNN, 유사학교, 비교군, 벤치마크
유사학교는 선택 학교와 같은 학교급 안에서 확보된 변수로 비교한 참고군이다. 서버에 저장된 knn_basis와 similar_schools를 조회해 사용 변수와 비교군을 설명한다. 유사도는 성과·실력·투자 순위가 아니며 교육 효과의 인과 증거도 아니다. 비교군의 처방을 대상 학교에 자동 적용하지 않는다. 같은 학교급·변수 범위의 자료가 없으면 비교를 보류한다.
