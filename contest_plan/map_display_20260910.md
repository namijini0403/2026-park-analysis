# 필요한 정보만 선택하는 지도

코드 커밋 `12c4a51`, 브랜치 `feat/all-school-levels-academy-public-metrics`.

## 사용자 흐름

1. 첫 화면은 학교 마커와 접힌 ‘지도 표시’ 메뉴다. 학교는 기본 단색으로 표시한다.
2. 학교급·지역·학교 검색으로 관심 학교를 선택한다. 유치원·중고등학교 선택 시 보고서를 자동으로 열지 않는다.
3. ‘학교만 / 공원 도보권 / 도서관 주변 / 학원 주변’ 구성 중 하나를 고르거나 개별 표시 항목을 선택한다. 구성 선택은 이전 추가 레이어를 교체한다.
4. 도보망·직선 500m는 기본적으로 선택한 학교의 고유 ID에 해당하는 도형만 표시한다. ‘현재 학교·지역 필터 전체’로 비교 범위를 바꿀 수 있다.
5. 공원·도서관·학원·재개발·주변 행정 시설은 기본적으로 선택 학교의 직선 2km 안만 표시한다. ‘전체 시설’로 전환할 수 있다. 이 2km는 화면 표시 제한이며 기존 분석 거리나 도보권 정의를 바꾸지 않는다.
6. 정책·개발 정보와 학교 진단 필터는 별도로 펼친다. 정책 분류 색상도 사용자가 켠다. 후보지·지정학교에는 시설의 2km 표시 제한을 적용하지 않는다.
7. 추가 분석·공개자료는 버튼을 눌러 연다. ‘학교만’으로 추가 레이어와 별도로 표시한 경로를 정리한다.

선택한 학교가 없으면 선택 학교 전용 도형·주변 시설을 표시하지 않고 학교 선택 안내를 제공한다. 모든 데이터 삭제나 분석 재계산은 없다. 모바일에서도 지도 표시 메뉴는 상세 패널과 독립적으로 열고 닫으며, 닫힌 상태에서는 한 줄로 유지한다.

## 도보권 확인

`education/school_analysis.json`과 `education/walkshed_500m.geojson`의 학교 ID를 대조했다.

| 학교급 | 기관 수 | 자체 도보권 ID 확보 |
|---|---:|---:|
| 유치원 | 369 | 369 |
| 중학교 | 147 | 147 |
| 고등학교 | 129 | 129 |

기존 초등학교 자료와 결합한 실제 앱 전환 경로에서 학교급별 도보권·직선 버퍼 선택을 검증했다. 도보권은 공개 보행망 기반 500m 거리이며 실제 출입구·통행허용·안전·나이별 보행시간을 검증한 통학로가 아니다.

## 검증

`npm run test:education`의 6개 테스트 통과. 최종 지도 변경 후 `node tests/test_education_app_startup.cjs`를 다시 통과했다. 실제 파일과 페이지 코드를 실행하고 외부 지도 SDK만 모의 처리했다.

추가 검사: 기본 메뉴 접힘, 단색 표시 기본값, 학교급별 도보권 존재, 선택 학교만 도형 표시, 학교급 전환 시 이전 도형 제거, 주변 학원 범위와 전체 시설 전환, 구성 교체·전체 숨김, 메뉴 닫기, 학교 선택 시 보고서 자동 표시 방지, 상세 보고서 진입 유지.

실제 브라우저 연결 도구가 `Transport closed`를 반환해 실제 지도 렌더링·모바일 화면의 시각 검증은 수행하지 못했다. DOM 동작 테스트를 실제 지도 SDK 검증으로 표현하지 않는다.

Railway 배포 `c3d4767d-28a1-40cc-a77e-e8538474c697`의 최종 상태 `SUCCESS`를 확인했다. https://education-living-area-preview-production.up.railway.app 에서 `index.html`과 `assets/map-display.css`를 실제 HTTP로 가져와 로컬 SHA-256과 일치함을 확인했다. 접속 코드는 `2026`이다. 파일별 해시는 [실서버 검증 JSON](map_display_live_validation_20260910.json)에 보존했다.
