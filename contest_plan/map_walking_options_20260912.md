# 메인 지도 도보 옵션 복원

지도 → 지도에 함께 보기에서 **도보 500m 도달권**, **공원까지 보행 경로·거리**, **직선 500m 반경**, **학구도**를 각각 켜고 끈다. 도보권은 기본으로 켜져 있다. 선택 학교를 변경하면 보행 자료도 학교 ID로 다시 연결한다. 도보권·경로 전체 보기 버튼으로 표시 범위를 맞춘다.

초등학교는 `school_walkshed_500m_v3.geojson`, 그 외 학교급은 `education/walkshed_500m.geojson`을 사용한다. 보행 경로는 `education/school_routes.json`의 실제 확보 기록만 사용하고, 원자료의 경로선·거리·방법을 공개한다. 미확보는 경로 부재로 단정하지 않는다. 대표점 보행망 분석과 실제 출입구·통행허용·안전 확인을 구분한다.

독립적인 체크박스, 지연 응답 시 학교·옵션 변경 보존, 요청 실패 재시도, 자료별 캐시를 적용했다. 기존 학교급 선택·직선 반경·공식 학구도를 유지한다. 변경한 런타임 파일은 `index.html`, `assets/school-map.js` 두 개다.

검증: `tests/test_school_map.cjs`, `tests/verify_walking_map_browser.cjs`. 실제 카카오맵에서 인천신흥초등학교 도보권 도형 및 학교 ID 연결, 산마을고등학교 공원 보행망 거리 11,754.8m, 독립 토글, 학교 선택 해제, 초등학교 경로 미확보 안내, 모바일 너비를 확인한다.

운영 배포 `91fdf774-932a-4457-8dc8-0ef9f5454bf7` SUCCESS 및 실제 카카오맵 운영 브라우저 검증 통과. 배포 JS 해시가 로컬 검증본과 일치한다.
