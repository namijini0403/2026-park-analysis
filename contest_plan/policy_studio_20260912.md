## 무엇을 결론으로 보여주는가

- 장서(권), 도서관 좌석(석), 사서 인력(명), 공원 확충 검토(곳)의 수량 시나리오를 제공한다. 공원 수는 관측한 공원 수이며 실제 적정 면적·수용량을 의미하지 않는다.
- 사용자가 자원·학교급·관측연도·지역·일반/도서·농어촌 검토 집단, 학교당 목표, 단가, 예산, 가중치와 선택 이유를 입력한다. 단가는 사용자 가정이며 견적이나 공식 지원 단가로 자동 인정하지 않는다.
- 첫 표: **학교 / 현재 수량 / 선택 목표 / 목표까지 수량 / 이번 지원·예산 / 순서·다음 행동**. 학교를 검색해 전체 행을 볼 수 있다.
- 목표까지 수량 = `max(0, ceil(사용자 목표 - 관측량))`. 자료 미확보는 0이 아닌 ‘계산 보류’다. 목표 차이는 정책적으로 확정한 부족량이 아니다. 학교당 동일 목표라는 가정은 화면에 명시한다.
- 실행 조건을 통과한 학교 안에서만 사용자가 선택한 비중으로 비교한다. 비교값은 `가중치_수량 × 수량차이/비교집단 최대차이 + 가중치_학생 × 같은연도 학생수/비교집단 최대학생수`를 가중치 합으로 나눈 값이다. 다른 자원이나 도서지역을 합산하지 않는다. 공원·독서 등급을 숫자로 합산하지 않는다.
- 비교값이 같으면 같은 단계로 유지한다. 예산은 정수 단위로 배분하고 동순위의 잔여 단위는 임의로 학교명 순서대로 나누지 않는다. 미배분 예산을 공개한다.
- 수량차이만 중시 / 학생 규모만 중시로 바꿨을 때 학교별 지원량을 함께 보여준다. 동일 연도 학생 수가 없으면 해당 비교는 보류한다.

실제 자료 계산 예: 인천신흥초등학교의 2025 장서 관측은 19,013권이다. 사용자가 **학교당 30,000권**을 목표로 선택하면 차이는 **10,987권**이다. 이는 기능 검증에 사용한 가정이며 채택한 정책이나 이 학교의 확정 지원량이 아니다.

현재 원자료만으로 네 가지 실행 조건이 모두 확인된 학교는 없으므로, 실제 학교의 집행 순서를 임의로 만들어내지 않았다. 대신 학교명·수량차이·필요 확인 항목을 표에 공개한다. 담당자가 근거를 등록하면 재계산 시 해당 학교들이 지원 비교·배분으로 넘어간다.

## 담당자 확인과 재계산

자격·안전·실행·실제 이용 경로마다 상태, 근거 문서명/URL/쪽수, 확인 내용, 문서 발췌, 담당자, 유효기간을 기록한다. 적용되지 않는 조건은 이유를 남긴다. 예를 들어 학교 안에서 사용하는 장서는 외부 도서관으로의 이동 경로를 검증했다고 표시하지 않고 해당 지원에 경로가 적용되지 않는 이유를 검토한다.

이 등록은 전용 근거 확인 인증값(`POLICY_REVIEW_TOKEN`, 없으면 `UPDATE_CENTER_TOKEN`)이 설정된 서버에서만 허용한다. 문서 발췌를 AI가 자동 사실 인증하거나 정책 승인으로 바꾸지 않는다. 서버 저장소에 버전과 감사 기록을 남기며, 요청 본문의 `gates`, `records`, 과거 추천 주장은 채택하지 않는다. 지원 목표 수량 변경·원자료 해시 변경·확인 만료·안전 실패는 재계산에서 제외한다. 운영 영속성은 기존 저장소 설정(Postgres 또는 영구 볼륨)에 따른다.

## 시각화

- 카탈로그 **42개 자료 영역, 1,181개 보기**를 `data_processed/visual_atlas/`에 사전 제작했다. 제작일·출처·원자료 해시를 포함한다. 원자료 변경을 해시로 감지하면 해당 영역의 시각화를 재제작·캐시한다. 처음 제작한 나머지 영역은 그대로 재사용한다.
- 연도·학교급·단위·시나리오를 분리한 분포, 기존 시계열·산점도·공간 자료, 원장 표를 상황에 맞게 제시한다.

- 펼친 값 구간 막대 클릭 → 해당 구간의 구성 학교 목록과 지도. 지도 연결이 안 되면 학교·지역·좌표 표를 유지한다. 대표 좌표를 출입구 보행 접근성으로 해석하지 않는다.
- 표는 검색과 20행 단위 탐색을 제공한다. 종전 12/20행 잘라내기를 제거했다. 학교별 지원 결과는 지도보다 먼저 표시한다.
- 수치 시각화는 공공 관측에서 생성했다. ImageGen으로 실제 수치나 지도를 합성하지 않았다. 시각 자료 조회에 추가 LLM 호출이 필요하지 않다.
