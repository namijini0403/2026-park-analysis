# 학교 분석·질문 UX 수정 (2026-09-19)

- 레이더는 바깥쪽일수록 긍정이다. 부정 지표는 표시 반지름만 `100 − 원자료 백분위`로 변환한다. 원자료와 상세 막대는 유지한다. 중립 지표는 별도 안내하고 결측은 끊어진 축으로 남긴다. 종합점수·투자 순위는 생성하지 않는다.
- 학교명·학교급은 식별·범위 조건으로 처리해 선택 후보에서 제외한다. 도서관 지원에는 주변 공공도서관 거리·보행권 도서관 수, 공원 정책에는 경로·공유 면적, 통학 정책에는 사고 근접성 등 목적에 관련된 후보를 제공한다. 관측은 안전 검증을 대체하지 않는다.
- 변수 확정 후에는 재질문 도구를 제거하며 오류 재시도에서도 확정한 변수를 유지한다.
- 지도 점에 적용되던 공통 버튼 최소 높이를 해제한다. 질문 지도 점은 9px, 선택한 점은 13px다. 지도 SVG에 통계 차트 높이 규칙을 적용하지 않는다.
- 동일 근거 표·섹션 중복을 제거하고 종합결론 뒤에 변수별 관측·수치 표를 접어 제공한다. 설명 API 실패 시에도 실제 조회 목록의 공통점·차이를 먼저 요약한다.
- 검토 기록은 대화 저장과 다르다. 담당자 목적·판단 이유·후속 확인사항을 관측 근거와 함께 기록하는 기능이므로 삭제하지 않고 ‘담당자 검토 메모’로 명칭·설명을 바꾼다.
- 운영 Google 학교·시설 사진은 실브라우저에서 표시된다. 로컬 미리보기 서버의 `/api/google-places-config` 누락을 복구했다. Google에 사진이 등록되지 않은 장소까지 사진 존재를 보장하지 않는다.

## 검증

통과: 기존 `test:agent` 5개, 신규 `test_variable_selection_once`, `test_agent_synthesis`, `test_answer_display`, `test_indicator_charts`, `test_school_profile_ui`, `test_profile_guardrails`, `test_observation_restore`, `test_distribution_guardrails`, `verify_table_comparison`, `verify_answer_display_browser`.

브라우저 증거: `outputs/answer-display-20260919/desktop.png`, `mobile.png`, `validation.json`; `outputs/photo-auto-20260919/radar.png` 및 사진 검증 캡처. 답변 화면 fixture 검사는 CSS·배치·중복 제거를 검증하며 실 AI와 SDK 검증과 구분한다.

사진은 `verify_photo_auto.cjs`에서 초기 학교·세모공원·학교 재선택·모바일 표시를 확인했다. `verify_photo_lifecycle.cjs`에서는 Google 원본 위젯을 유지한 채 부개초→운남초→부개초 전환, 검색 응답, 실제 사진 화면을 확인했다(`outputs/photo-lifecycle/1.png`, `2.png`). Google 내부 shadow root를 변경한 이전 검사에서만 전환 지연이 나타났으므로 제품 lifecycle 결함으로 기록하지 않는다.

기존 전체 검사 중 별도 실패: `test_school_profile.cjs`는 유치원의 `designations_current`가 항상 null이라는 오래된 기대값에서 현재 0 관측과 충돌한다. `test_hitl_analysis.cjs`는 현행 질문 API와 다른 과거 `hitl_plan.catalog` 응답을 기대한다. 이번 작업에서 해당 데이터·API 계약을 변경하지 않았다. 현재 경로의 누락·안전·점수 금지·저장 결과 복원 검사는 통과했다.

운영 배포는 현재 성공 배포 `eb6c379c-72d5-4811-91c0-7840ce05bbd8`와 해시를 대조한 별도 복사본에 요청 관련 10개 파일만 덮어쓴다. 서버에서 갱신된 공개 데이터는 현재 서버의 해시와 검증한 값을 보존한다. 기존 작업 중인 갱신 센터 파일은 이 변경에 포함하지 않는다.

첫 배포 `e5d94c27-824d-4470-b7f1-35de9b6ddfc9`는 잠시 SUCCESS 이후 CRASHED로 전환되었다. 상위 저장소의 `vercel_public/` 제외 규칙을 업로드가 적용해 공개 데이터가 빠진 것이 원인이다. 격리된 배포 폴더 업로드에 `--no-gitignore`를 적용하고 Docker 빌드에 필수 공개 파일 존재 검사를 추가했다. 단순 배포 상태뿐 아니라 공개 파일 해시·API·브라우저 응답을 모두 확인한다.

복구 배포 `181afe70-87da-4092-a7bc-8f311c58c7e9`는 SUCCESS이며 실제 서버 listen, 저장 데이터 복원(3개 데이터셋), 공개 파일 8개 해시 및 프로필 API 검사를 통과했다. SSH로 확인한 `api/_agent.js`, `api/chat.js`의 해시도 수정 원본과 일치한다. 공개 주소: https://education-living-area-preview-production.up.railway.app/

실제 공개 질문 ‘학교 도서관 지원을 검토할 초등학교 5개를 찾아줘’ 검증도 통과했다. 변수 제안 1회 → 선택 확정 1회 → 실제 AI 종합결론으로 이어졌으며 학교명·학교급 후보 제외, 주변 공공도서관 거리 포함, 재질문 없음, 실제 Kakao 지도 타일과 9×9px 점, 중복 표 없음, 접힌 세부 관측, 모바일 폭을 확인했다. 응답은 도서·농어촌 5개교가 조회된 공통점을 먼저 설명하고 소규모 학교군 별도 검토 및 판단 유보를 밝혔다. 증거는 `outputs/question-ux-live-20260919/validation.json`, `responses.json`, `live-map.png`, `live-answer-desktop.png`, `live-answer-mobile.png`에 있다.

데스크톱 근거 패널은 내부 스크롤 구조다. 지도 아래 세부 항목을 스크롤해 클릭하고 수치 표를 펼쳐 실제 5개교×4변수 표가 보이는 것까지 검증했다(`live-details-expanded.png`, `drilldown-validation.json`).
