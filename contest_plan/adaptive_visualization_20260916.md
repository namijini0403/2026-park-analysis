# 전체 통계와 다변수 시각화 재구성 (2026-09-16)

문제: 큰 설명·수치 카드가 분포 차트를 아래로 밀었고, 챗봇 비교 화면은 변수를 4개로 제한했다. 서버도 요청 열을 9열에서 조용히 잘랐다.

변경:
- 전체통계 기본 화면에 값별 학교 수 분포와 군·구 중앙값 막대 차트를 함께 표시한다. 작은 정수 범위는 0·1·2 등 실제 값별 학교 수를 표시한다.
- 큰 카드와 사분위 범위선은 접힌 수치 상세로 이동한다. 선택 학교의 구간은 주황색으로 표시하고 지역 막대 클릭은 해당 학교 목록으로 연결한다.
- 기본적으로 받은 모든 숫자 변수를 선택한다. 1~4개는 막대, 5개 이상은 학교×변수 히트맵을 자동 선택하며 사용자가 모드를 바꿀 수 있다.
- 크게 보기에서 10개 숫자 변수를 동시에 확인할 수 있다. 닫기/Esc 후 선택 상태 유지, 새 답변 렌더 시 대화상자 제거.
- query_schools는 모든 요청된 유효 열을 반환한다. 단일 응답의 학교 수 상한은 기존 50개를 유지한다.

해석:
색 농도는 각 변수 자체의 최소~최대 사이 위치이며, 단위가 다른 변수의 색끼리 우열을 비교하거나 합산하지 않는다. 결측은 무늬와 자료 없음으로 표시하고 0·음수·상수와 구분한다. 범위는 표 전체 행 기준으로 페이지를 넘겨도 유지한다. 원본 표와 출처 링크를 보존한다. 강화·옹진 별도 검토와 PAPS 비교 제외를 유지한다.
