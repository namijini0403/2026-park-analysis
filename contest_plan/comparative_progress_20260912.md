# 질문 기반 복합 비교 분석 — 구현 및 검증

원래 목표를 유지했다. 한 학교의 단일 수치를 조회하는 방식에서 여러 자료·비교집단·시각화를 결합하는 방식으로 확장했다. 기본 화면은 기존의 단순한 화면이며, 복잡한 자료는 질문한 뒤 오른쪽 근거 패널에 나타난다.

## 요구사항과 구현 증거

| 요구 | 구현 | 검증 |
|---|---|---|
| 도서관 접근·장서 근거 결합 | 거리·도달권 포함 여부·장서 총수/학생당 장서/좌석/사서 분리 | 석암초 397m, 장서 20,761권, 학생당 23권 및 출처 행 대조 |
| 다른 학교와 상대 비교 | 동일 학교급·도서지역 구분, 자기 학교 제외, 유사 규모 ±20%, 환경 변수별 허용 범위 | 비교집단 ID 및 중앙값 회귀 검사 |
| 상황에 맞는 시각화 | 지도·비교 막대·선택 학교 강조 산점도·시계열·격자 분포 상자그림 | 실제 Leaflet/DOM 검사 및 42개 자료군 실행 |
| 전체 보유 자료 영역 | 기존 42개 정규 자료군과 초등학교 보충 원장 연결 | comparative_domain_validation.json |
| 범주·기간별 올바른 비교 | 동일 대회/부문·연도, 운동부 종목별 최신 게시, 과목 제공/참여 연결, 예측/관측·시나리오 분리 | 중복 공시·미래 비교연도·범주별 실자료 사례 검사 |
| 결측과 자격 조건 유지 | 미수집 지역을 0으로 바꾸지 않음, 외부 돌봄 집계에서 학교 재학생 전용 시설 제외 | 운동시설 부분 수집 지역 검사 및 기존 정책 회귀 검사 |
| 보고서·전체 표 저장 | 여러 차트·정식 표·출처를 Word/PNG로 저장, 전체 표 CSV | 실제 PNG/DOCX 생성 및 LibreOffice 10쪽 렌더링 시각 확인 |
| 앱 실제 실행 | 단일 /api/chat 경로, 왼쪽 답변·오른쪽 복수 근거 | comparative_live_validation.json의 7개 실요청 및 출처 파일 HTTP 확인 |

## 실행 확인

- `node tests/test_comparison_domains.cjs`: 42개 자료군, 유한 수치, 표/CSV 열 수, 자기 학교 제외, 과거 점수 제외, 장서 원자료, 미래 비교연도, 결측, 최신 공시와 중복 날짜 처리.
- `node tests/test_comparative_evidence.cjs`: 석암초 정확한 수치, 지도·산점도, 주요 분야, 지역 인구와 학교 예측 구분, 정책 판단 제한.
- `node tests/test_chat_workspace.cjs`: 복수 차트·표·실제 Leaflet 마커, 선택 학교 강조, 답변 전환 및 HTML 이스케이프.
- `npm run test:simple`: 단일 챗봇·기존 정책 불변식·과거 저장 데이터 회귀 검사.
- `node tests/test_data_catalog.cjs`: 기존 42개 자료 조회 유지.
- `COMPARATIVE_QA=1 node tests/test_answer_export.cjs`: 복합 보고서 생성. PowerShell에서는 `$env:COMPARATIVE_QA='1'` 설정 후 실행.
- `npm run build:vercel`: 정적 자료와 최신 UI 빌드 완료.
- `node tests/test_comparison_http.cjs`: 실행 중인 localhost:3088에서 실요청 확인.

## 해석과 운영 범위

- 데이터는 보유한 수집 스냅샷이다. 자료가 없거나 단위·기간·대상 범위가 다르면 이를 명시하며 학교의 결핍·지원 우선순위를 만들어내지 않는다.
- 비교집단은 재현 가능한 기술적 비교 기준이다. 같은 안전·자격·정원·운영 조건을 보장하거나 정책 선호를 대신하지 않는다.
- 초등학교에는 별도 도서지역 표기를 적용한다. 해당 표기가 없는 학교급의 강화/옹진 분리는 잠정 기준임을 답변에 명시한다.
- 지역 인구·전체 격자·확산 시나리오는 학교 고유 관측과 구분한다. 다른 단위를 학교 수치처럼 합산하지 않는다.
- 범주형 자료에 자연스러운 공통 숫자가 없으면 동일 범주의 기록 분포·공고상 관계를 제시한다. 수상·지정 기록을 학교 품질 점수로 바꾸지 않는다.
- PNG의 지도는 출처 좌표를 사용한 보고서 위치도이며 배경지도·실제 도보 경로가 아니다. 긴 보고서는 Word를 이용한다. Word의 큰 개별 표는 표시 한도를 알리고 전체 CSV를 제공한다.
- 원래 DATA_ROCK HWP는 변경하지 않았다. 운영 배포/커밋은 하지 않았다.
- 사용 가능한 CUA 브라우저가 없어 실제 브라우저 화면의 픽셀 검수는 수행하지 못했다. DOM/Leaflet 통합과 실제 내보내기 문서 렌더링은 검증했다.
