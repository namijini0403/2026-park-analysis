# 시각·구조 최적화 작업 기록

2026-09-11 업데이트: 별도 브라우저 제어 경로를 복구해 실제 화면 검증과 후속 수정을 진행했다. 아래 이전 차단·미검증 기록의 최신 판정은 [완료 검증 기록](workspace_ux_completion_20260911.md)과 [최종 배포 해시](workspace_final_live_validation_20260911.json)를 따른다.

## 목표와 완료 증거

사용자가 처음 들어와 학교를 찾고, 지도 정보를 선택하고, 질문·통계·학교 분석으로 이동하는 흐름을 단순화한다. 기존 화면 보존 자체를 목표로 하지 않는다.

완료 판단에는 다음 증거가 모두 필요하다.

1. 검색·선택·분석의 정보 구조가 명확하며 중복 진입점이 전면을 차지하지 않는다: 실제 DOM 및 대표 작업 수행.
2. 선택하지 않은 학교가 임의로 분석되지 않고 학교급·지역·선택 학교가 유지된다: 실제 데이터 통합 테스트.
3. 기본 지도와 분석 화면에서 사용자가 요구하지 않은 고밀도 정보가 펼쳐지지 않는다: 기본 상태 테스트와 실제 화면 확인.
4. 데스크톱·작은 화면에서 검색, 메뉴, 지도, 상세 패널이 겹치거나 잘리지 않으며 키보드로 접근할 수 있다: 실제 브라우저 렌더링 및 조작.
5. 기존 학교급별 도보권·시설·분석 기능을 사용할 수 있다: 회귀 테스트와 대표 실사용 경로.
6. 배포 결과가 검증 코드와 일치하고, 가이드의 실제 화면 안내가 새 구조와 일치한다: 배포 파일 해시 및 가이드 확인.

실제 브라우저가 없으면 4번과 6번의 화면·가이드 검증을 완료로 인정하지 않는다.

## 참고한 다른 앱의 구조

- [Google Maps 주변 탐색](https://support.google.com/maps/answer/4610185?co=GENIE.Platform%3DDesktop&hl=en-en): 장소를 먼저 찾고 그 주변을 탐색하는 흐름. 이 앱에서도 선택 학교를 분석 기준으로 삼으며 임의 학교 자동 선택을 제거한다.
- [Google Maps 표시 정보 선택](https://support.google.com/maps/answer/3092439?hl=EN): 기본 지도와 추가 표시 정보를 별도 레이어 선택으로 제공. 필요한 정보를 더하는 지도 메뉴를 유지한다.
- [ArcGIS Map Viewer 시작하기](https://doc.arcgis.com/en/arcgis-online/get-started/get-started-with-mv.htm): 지도 작업 공간을 넓히기 위해 도구를 접을 수 있는 구조. 이 앱은 전문 GIS 기능 전체를 복제하지 않고 주요 기능과 보조 도구를 구분한다.

## 이번 변경

- 학교급·지역·학교명을 같은 검색 영역에 배치하고 현재 선택을 표시한다.
- 전면 기능을 학교 분석·질문 분석·통계 비교 세 개로 정리한다. 공개자료·시뮬레이션·도움말·관리 등은 더 보기에서 접근한다.
- 학교를 고르지 않고 학교 분석·시뮬레이션을 요청하면 선택을 안내한다. 우선순위 점수가 높은 학교를 임의로 선택하지 않는다.
- 인증 후 별도 소개 화면을 한 번 더 통과하지 않고 지도로 진입한다. 인증 코드 검사는 유지한다.
- 질문 분석 화면은 질문 입력을 우선 제시하고, 미리 계산한 정책 분석 5가지는 접어서 제공한다.
- 상단 탐색 영역을 반응형 배치로 통합하며 보조 메뉴의 Escape·바깥 클릭·선택 후 닫기를 제공한다.

## 현재 검증 한계

브라우저 제어 도구의 조회와 세션 재설정 모두 `Transport closed`를 반환했다. 실제 지도 SDK 렌더링, 작은 화면에서의 가림 여부, 전체 시각 조화와 가이드 스크린샷 검증은 미완료다. 이 제약만으로 전체 목표를 완료 처리하지 않는다.

## 이번 실행 결과

- `npm run test:education` 6개 테스트 통과. 패널 배치 변경 후 실제 데이터 기반 `test_education_app_startup.cjs`도 재통과했다.
- 선택 없는 보고서 요청의 임의 학교 선택 방지, 통합 검색 안의 지역 필터, 전면 분석 버튼 3개, 보조 메뉴 기본 접힘, 정책 분석 기본 접힘을 통합 테스트에 추가했다.
- 상세 패널은 ResizeObserver로 파악한 상단 탐색 영역 아래에 배치하며, 지도 표시 메뉴와 상세 패널을 동시에 펼치지 않는다. 이는 코드 보완이며 실제 렌더링 검증을 대신하지 않는다.
- Railway 배포 `f72287a0-8fed-4210-9b15-7c082ca5271c` 상태 `SUCCESS` 확인. 목표 전체는 실제 화면·가이드 확인이 남아 **진행 중**이다.

## 가이드 정합성 보완

현재 사용 순서를 네 단계로 제공하고 지도·질문 분석으로 직접 연결했다. 예전 초등학교 중심 스크린샷과 전문 분석 설명은 별도 접힌 참고 영역으로 이동하고 이전 화면임을 명시했다. 학교 수 안내는 전체 학교급 917개 기관으로 수정했으며, 학교급별 자료 범위의 차이를 표시했다. 과거 화면을 새 화면의 검증 증거로 사용하지 않는다.

현재 완료 감사: 탐색 구조·임의 선택 방지·기본 접힘·학교급 회귀는 DOM/실제 데이터 테스트로 확인했다. 가이드의 최신 사용 순서와 과거 화면 구분은 코드와 DOM으로 확인할 수 있다. 실제 데스크톱·모바일 지도 렌더링, 가림 여부, 키보드 실사용 및 전체 시각 조화는 브라우저 연결 `Transport closed`가 계속되어 미검증이다. 따라서 전체 목표는 완료가 아니다.

가이드 코드 `09a71d6`의 통합 테스트에서 네 단계 안내, 참고 영역 기본 접힘, 단일 접근성 제목 ID, 지도 이동 버튼을 확인했다. 배포 `4f2086ac-731f-4521-b43f-9d47ebf97250`은 `SUCCESS`이며 HTML·스타일·분석 UI 스크립트 3개를 실서버에서 받아 로컬 SHA-256과 일치함을 확인했다. [현재 배포 검증](workspace_ux_live_validation_20260910.json).

브라우저 연결 실패는 직전 목표 턴에 이어 이번 목표 턴의 `cua.getState()`에서도 재확인했다. 이번 턴에는 가이드 정합성 개선·테스트·배포라는 실제 진행이 있었으므로 대기 상태만 반복한 것은 아니다. 다음 검증에서 기존 배포·테스트를 이유 없이 재실행하거나 시각 검증을 DOM 검사로 대체하지 않는다.
