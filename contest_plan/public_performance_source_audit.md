# 학교 실적 공개자료 추가 조사 (2026-09-09)

수능·학업성취·진로·대외 실적의 공개 경로를 추가 조사했다. 검색 결과만으로 자료 부존재나 수집 완료를 판정하지 않는다.

## 자율공시 파일: 실제 다운로드와 스키마 확인

- 제공기관: 한국교육학술정보원.
- 공식 페이지: https://www.data.go.kr/data/15156384/fileData.do
- 자료명: 학교알리미 자율공시내역, 기준 2025-09-30.
- 공개 다운로드 사전 확인 `check-limit.json` 응답은 `needCaptcha: false`였다. 인증을 우회하지 않고 사이트의 다운로드 절차로 파일을 확인했다.
- CSV 실제 크기: 18,088행, 4열. 열은 `공시연도`, `공시차수`, `자율공시제목명`, `자율공시내용`이다.
- 학교 코드·학교명·지역을 지정한 식별자 열이 없다. 일부 본문/제목에 학교명이 등장하지만 전체 학교의 정확한 대응표가 아니다. 이 자료를 원장에 임의 연결하거나 전수 수상 지표로 만들지 않았다.
- 파일 해시·다운로드 URL·실제 열 목록: `data/education_sources/public_performance_review/autonomous_disclosure_schema.json`. 개인 이름을 포함할 수 있는 전국 자유서술 원문은 새 데이터셋으로 보존하지 않았다.

## 진학·취업 자료 검색 범위

- 학교알리미 공시항목 소개에서 직업계고 졸업생 진로 항목을 확인했다: https://schoolinfo.go.kr/si/pi/pnsipi_a01_l0.do
- 하이파이브 공식 포털을 추가 공개 경로로 확인했다: https://www.hifive.go.kr/
- 초기 조사에서는 인천 학교별 진학·취업 수치 일괄 파일을 확보하지 못했으나, 후속 KEDI 데이터셋 조사에서 아래와 같이 확보했다. 이는 해당 자료가 존재하지 않는다는 판단이 아니다.
- 지역 단위 통계나 오래된 단일 학교 홍보기사를 현재 학교별 비교 수치로 대체하지 않았다.

## 확보된 공시의 학교명 차이 복구

학교 위치 원장 `인천재능중학교`·`인천재능고등학교`와 학교알리미 `재능중학교`·`재능고등학교`의 표기 차이를 확인했다. 2026년 공식 기본정보의 같은 학교급, 인천광역시, 도로명·건물번호 `재능로 178`, 200m 이내 좌표를 함께 대조했다. 행정구역 명칭 차이는 도로명·건물번호 일치와 좌표 검증으로 보완하고, 단순 이름 유사도만으로 연결하지 않는다. 동일 조건의 후보가 복수이면 보류한다. 검증된 학교알리미 코드를 사용해 과거 공시도 같은 학교로 연결한다.

근거와 매칭 방법은 `data_processed/education/schoolinfo_verified_aliases.json`에 남긴다. 이 복구는 공개자료가 없던 문제가 아니라 식별자 체계와 이름 표기의 차이 때문에 누락됐던 문제를 해결한다.


## 공시 수집 실패 36건 재확인

2026-09-09에 기존 manifest의 실패 요청만 같은 공식 공개 계약으로 재확인했다. 정상 확보한 221개 요청의 원본은 다시 다운로드하지 않았다. 신규 공시 행은 확보되지 않았다.

| 공식 응답 구분 | 요청 수 | 처리 |
|---|---:|---|
| 2026-10-01 공개 예정 | 10 | 현재 미공개로 보류. 공시 없음·0값으로 해석하지 않음 |
| JSON 응답에 공개 list 없음 | 8 | 공개 목록 미확보 유지. 자료 부존재로 판정하지 않음 |
| 비 JSON 응답 | 18 | 응답 형식 문제로 미확보 유지 |

공개 예정 10건은 자유학기제 1건, 국공립 회계 3건, 사립 회계 3건, 교복 구매 3건이다. 목록 미확보 8건은 환경위생관리 6건과 초등 표시과목별 교원 2건이다. 비 JSON 18건은 국공립·사립 회계 각 9건이다. 같은 항목 안에서도 공시연도·학교급·세부 깊이가 다른 요청을 구분한다.

공식 응답의 `2026년 정보는 2026년 10월 01일 공개됩니다.` 문구를 정확히 대조해 공개 예정 상태를 분리했다. 응답 HTTP 상태·바이트 수·SHA-256·공개 예정일은 `data/education_sources/disclosures/retry_audit.json`에 보존했다. 기존 실패 이력은 유지하며 재확인 결과는 별도 감사 파일로 제공한다.

재확인 명령: `python -X utf8 -m scripts.education.retry_disclosures`. 자동 반복 작업은 등록하지 않는다. 검증에서는 비 JSON·HTTP 오류·목록 없는 JSON이 빈 데이터로 처리되지 않는지, 명시적 빈 목록과 실제 0값 공시행이 구분되는지, 공개 예정 응답에서 예정일을 보존하는지 확인했다.


## 신검단 학교 식별 불일치

학교별 연결 점검에서 `B000030928` 원장이 이름은 인천신검단중학교, 학교급은 초등학교로 기재되고 연결 공시가 0건임을 확인했다. 인근 인천신검단초등학교의 2026 학교알리미 기본정보(`S040002358`)는 별도 학교이며 임의 연결하지 않는다.

- 예정 중학교의 공식 근거: https://www.ice.go.kr/ice/na/ntt/selectNttInfo.do?bbsAllView=Y&bbsId=1981&mi=&nttSn=3358686
- 현재 교육청 학교현황 검색: https://www.ice.go.kr/ice/func/spm/selectSpmUserList.do?searchWord=신검단&currPage=1 — 이번 응답에서는 신검단초등학교만 확인했다.
- 나이스 공개 schoolInfo의 정확 이름 `인천신검단중학교` 및 참고 학교코드 `7361340` 조회는 INFO-200으로 목록이 없었다. 코드 참고값 자체를 공식 식별 확인으로 간주하지 않는다.
- 이 결과는 중학교 부존재·폐교 확정의 근거가 아니다. 현재 기관 식별·운영 정보를 보류하며 위치 원장의 명칭만으로 학교급을 바꾸지 않는다.


## KEDI 학교별 졸업·진학·취업 지표 확보

공공데이터포털 https://www.data.go.kr/data/15139276/fileData.do 에서 교육통계서비스의 실제 학교별 데이터셋 경로를 확인하고 2025·2026년 상반기 엑셀을 내려받았다. https://kess.kedi.re.kr/contents/dataset?itemCode=04&menuId=m_02_04_03_02&tabId=m1

- 2025년 조사기준일 2025-04-01, 추출일 2026-02-06. 2026년 조사기준일 2026-04-01, 추출일 2026-09-03.
- ‘학교별 주요통계’ 시트 17행의 학교명·시도·학교급·KEDI 학교코드 및 졸업 후 상황 열을 읽었다. 졸업자는 해당 연도 2월 졸업자이며, 진학자는 진학 학교에 등록한 학생이다. 공개 진학률은 진학자/졸업자 기준이다.
- 원본 8행 주석에 따르면 고등학교 졸업 후 상황은 직업계고 취업통계 발표(11월) 이후 갱신된다. 2026년 자료의 고등학교 진로 칸 0은 전체 129교에서 미공개로 처리하며 졸업자 수만 보존한다. 2025년 값은 별도 연도로 제공한다.
- 중학교146교·고등학교129교, 총275교에 548개 연도별 관측을 연결했다. 2025년은 정상270·졸업자0인 학교3, 2026년은 정상144·졸업자0인 학교2·고교 진로미공개129다. 졸업자0의 진학률은 null이다. 공표 진학률과 인원 계산을 대조한 불일치는 없었다.
- 명칭이 다른 재능중·고교는 기존 검증된 명칭 별칭에 더해 KEDI의 인천 도로명·건물번호 일치를 확인했다. 다른 학교는 인천 내 학교명·학교급 유일 일치로 연결했다.
- KEDI에만 있는 2026년 인천검단가온중학교(KEDI 234031642, 동화시로122)는 현재 원장과 미연결로 남긴다. 신검단 원장과 동일 기관인지 후속 공식 근거 대조가 필요하다.
- 정규화 원자료와 해시: `data/education_sources/kess_school_progression.json`. 분석: `data_processed/education/school_progression.json`. 후자는 원본 파일별 직접 다운로드 URL도 포함한다. 원본 엑셀은 Git 제외 outputs/education_sources에 두었다.

진학률을 대학 수준·수능 성적·학교 품질로 해석하지 않으며, 취업률을 새로 만들어 비교하지 않는다. ‘기타’는 재수·상황 미확인 등 여러 경우를 포함한다. 교육통계의 조사기준일 자료와 학교알리미 수시 공시를 서로 덮어쓰지 않는다.


## 신검단 식별 후속 결론

KEDI의 검단가온중학교와 학교알리미 S040002365·나이스7361341을 대조해 기존 위치 원장 B000030928을 보정하고 중학교 분석에 편입했다. 초기 조회의 실패는 옛 이름을 조회한 조사 이력으로 보존하며, 현재 미해결 상태가 아니다. 공식 이름·학교급·설립일 및 가까운 공식 좌표를 조합한 보정 근거는 school_registry_corrections.json에 있다. 교육청의 2026-03-01 신설 중학교 목록에도 검단가온중이 명시된다: https://www.ice.go.kr/ice/cm/cntnts/cntntsView.do?cntntsId=958&mi=10875

법적 교명변경 절차에 대한 판단은 하지 않는다. KEDI 진로의 미연결1건도 해소돼 중·고276교에 연결된다.
