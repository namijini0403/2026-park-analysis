# 공개자료 자동 갱신·반영 구현

## 운영 경로

매일 검사 → 실제 공개 응답 수집 → 내용 비교 → 격리된 작업 디렉터리에서 관련 산출물 재계산 → 스키마·학교 연결·커버리지·파일 해시 검증 → 영구 저장 → 지도·분석 파일 함께 반영.

원격 호출은 실패 시 최대 3회 재시도한다. 서버 재시작 시 활성 데이터 복원을 마친 뒤 요청을 받는다. 예정된 검사를 놓쳤으면 기동 시 추가 검사하며, 동일 프로세스에서 검사가 겹치지 않는다. 열린 지도는 60초마다 공개 버전을 확인하고 새 버전이면 새로고침한다. 문서 업로드 화면은 새로고침 대상이 아니다.

## 자동화 범위

| 자료 | 실제 자동 처리 |
|---|---|
| 공식 학구도 | 최신 공개 첨부 탐색, 인천 필터·좌표 변환·기하 검증, 지도 반영. 구역 수 급변·스키마 변경은 검토 대기 |
| 전국도서관표준데이터 | 전 페이지 수집, UTF-8 해석, 인천 필터, 기관별 최신 기준일 선택, 동일 주소의 검증된 좌표 보완. 학교 도보권 도서관 수·직선거리·독서 격차·정책 카드·7,304개 후보의 거리 시나리오·질문 분석·AI 근거 재계산 |
| 학교·유치원 공개 공시 | 등록된 당해·전년도 공시항목과 공개 차수 탐색, 기존 기관의 공식 코드 또는 학교급 내 유일한 정확한 이름으로 연결. 학교별 상세 공시·활동 지표·통계·질문 분석·AI 근거 갱신 |

공시 원문에 없는 수치는 만들지 않는다. 비공개·미공시·매칭 불확실한 값은 0으로 채우지 않는다. 도서관 좌표 미확보 시설은 `library_refresh_coverage.json`에 명칭·주소를 보존한다. 지도 및 접근성 수치는 좌표 확보 시설 기준 하한 관측치다. 동일 시설의 중복 제공자료는 최신 기준일을 사용하고, 좌표 보완은 주소 일치가 확인되는 경우에만 사용한다.

기관 신규 편입·이전과 도로망 재생성, 원출처가 확정되지 않은 공원·재개발 자료, 교육청 개별 첨부파일을 기존 가공 스키마로 바꾸는 미연결 경로는 아직 전체 자동 반영 대상이 아니다. 기존 12개 게시물 헤더 감시와 3개 수동 출처는 상태 화면에 그대로 구분한다. **전체 자료가 자동화된 것은 아니다.** 이미 작성된 미래 예측·검토 기준 스냅샷의 무검증 재학습도 수행하지 않는다. 현재 관측값의 갱신과 미래 수요 모형의 검증·재학습은 별도다.

학교 공시 갱신 후 교육청 업로드 문서를 다시 분석하면 서버의 최신 공시·환경 데이터와 결합한다. 업로드 수치를 공식 원자료에 덮어쓰지 않는다.

## 실패·복원·저장

- 원자료 레코드 급감, 좌표 오류, 학교 연결 손실, 산출물 계약 위반 시 기존 버전을 유지한다.
- 재계산 중 입력 파일이 바뀌면 낡은 계산 결과의 반영을 거부한다.
- 분석 묶음은 원본과 이전 파일을 영구 저장한 뒤 반영한다. 저장 실패 시 새 데이터가 공개되지 않는다.
- 동일한 내용을 SHA-256 기준 압축 blob으로 한 번만 저장한다. 버전·감사 로그 조회가 대용량 base64를 반복 파싱하지 않는다. 기존 저장 형식도 계속 읽는다.
- 관련 파일 교체 중 예외가 나면 같은 동기 실행 구간에서 이전 파일로 복구한다. 재기동 복원은 게시 순서대로 실행해 공유 분석 파일의 최신 버전이 마지막에 적용된다.
- Railway 영구 볼륨 `/app/data`를 계속 사용한다. 현재 단일 인스턴스 구성이다. 복수 인스턴스 운영으로 바꾸면 공유 잠금과 공통 저장소를 별도로 연결해야 한다.

## 검증

- 기존 업데이트 센터 검사 86개, 저장·복원 검사 76개 통과.
- 새 자동 갱신 검사: 실제 반영, 지도·분석 파일 일치, 압축 저장, 재시작 복원, 롤백, 저장 실패, 통신 실패, 낡은 입력, 경로 이탈 거부.
- 기존 분석 엔진/API/질문 UI, 전체 지도 초기화, 교육청 문서 결합·인증·보존 검사 통과.
- 실제 도서관 원자료 재계산: 9개 산출물 약 61MB, 지도 좌표 확보 251개·미확보 2개 기관.
- 실제 학교 공시 70,915개 연결 기록, 유치원 공시 19,991개 연결 기록 검사. 373개 산출물 약 36MB 검증. 매칭하지 못한 기관은 범위 밖 또는 불확실한 연결로 기록하고 임의 편입하지 않음.
- 운영 환경 최초 실행에서 누락된 `population_grid.csv` 계산 입력을 발견. 갱신 거부·기존 데이터 유지 확인 후 내부 계산용 배포 seed에 추가.

실제 운영 실행 및 재배포 후 해시 검증 결과는 `auto_refresh_live_validation.json`에 기록한다.

### 운영 확인 결과

- `v001`: 학구도, `v002`: 학교·유치원 공시, `v003`: 도서관과 관련 분석 묶음.
- 운영 서버의 도서관·공시 갱신이 검토 버튼 없이 `applied`로 완료됨.
- 같은 도서관 자료 재검사: 변경 없음 1건, 새 이벤트·새 버전 0건.
- 운영 질문 분석 API 정상 응답. 지도 및 분석 데이터는 917개 기관, 도서관 후보는 7,304개.
- 재배포 `94a7f030-1de2-42e0-9b4c-4d2248a3c3e3`에서 `SUCCESS` 확인. 도서관 원자료·학교 접근성·분석 데이터·학교 통계·도서관 시나리오·AI 근거의 6개 대표 파일 해시가 재배포 전후 모두 일치함.
- 학교 공시의 내부 관측 필드 삭제, 원격 레코드 20% 초과 감소도 검증에서 차단. 비공개/결측 값 자체는 유지. 실제 연결 공시 267개 파일 묶음으로 스키마 검증 확인.
- 일반 맥락 자료와 교육 공시의 AI 캐시, 열린 지도의 버전 변경 감지도 검증함.
- 최종 배포 `29d1f0a0-cd9e-40e5-b755-5ab5fe1ae403`의 `SUCCESS` 확인. 이 배포 후에도 동일한 6개 대표 파일 해시가 모두 유지됨.
