# 질문형 분석 재현·해석 기록

## 데이터와 실행 구조

`build_analysis_dataset.py`는 앱 편입 917개 기관을 학교 ID로 연결한다. 2025/2026년 공시, 현재 환경, 2020년 이후 확보한 학생·원아 이력과 기존 예측을 보존한다. 학교급을 섞지 않으며 공시연도 변경이 환경의 과거 시점을 복원하는 것은 아니다. 전년 증감은 연속한 두 관측 연도에만 계산하고 기준값 0의 증감률은 결측이다.

API `/api/analysis`는 자연어 또는 수정한 분석 계획을 받아 서버 자료만 계산한다. AI는 허용된 변수·방법의 JSON 계획만 반환하며 임의 코드·SQL을 실행하지 않는다. 클라이언트가 보내는 수치를 분석에 쓰지 않는다. `OPENAI_API_KEY`가 없거나 AI 응답을 얻지 못하면 규칙 기반 질문 해석을 사용한다. `AI_ANALYSIS_MODEL` 또는 기존 `AI_EXPLAINER_MODEL`을 사용할 수 있다. AI에는 변수 목록과 질문만 보내며 전체 학교 자료·계산 결과 행을 보내지 않는다. 답변 수치와 차트는 계산 결과에서 작성된다. 실제 API 키를 사용한 외부 모델 호출과 모의 응답 검증은 구분한다.

분석 기록 JSON에는 질문, 계획, 조건, 시각화 자료, 계산값, 한계, 자료 해시, 분석 ID를 남긴다. 최근 질문·계획은 해당 브라우저에 최대 10개 저장하고 다시 계산할 수 있다. 기록의 입력 해시가 달라지면 같은 질문도 다른 스냅샷이다.

## 분석 선택과 계산

- 관계: 완전 관측 쌍에서 Pearson 및 동점 평균 순위의 Spearman을 계산한다. 기본 최소 표본 8개. 조건 보정은 순위값에서 선택한 최대 3개 변수와 선택적 군구 더미의 선형 성분을 제거한 잔차 상관이다. Gram–Schmidt로 중복 설명 열을 제거하며 잔차가 사실상 0이면 미산출한다. 잔차 상관을 인과 효과라고 해석하지 않는다. 원래 관측값 산점도와 보정 계수는 구분한다.
- 두 지역 차이: 각 지역 완전 관측 5곳 이상에서 Cliff의 δ=(A>B 쌍 수−A<B 쌍 수)/(nA×nB)를 계산한다. 동점은 0 기여. 사분위 상자와 최소·최대, 표본 수를 표시한다. 유의성 또는 규모 보정을 한 차이로 주장하지 않는다.
- 격차: 비음수 지표의 기관 동일가중 지니계수와 Lorenz 곡선, 10·50·90백분위를 제공한다. 음수가 있으면 해당 관측을 버리지 않고 지니 대신 분위수 상자로 전환한다. 학생별·주민별 불평등과 다르다.
- 변화: 선택 범위에서 모든 관측 연도를 공통 확보한 동일 기관만 합산한다. 모든 연도 쌍의 연평균 기울기 중앙값(Sen)을 표시한다. 신설·폐원·결측 기관 제외 수를 공개한다. 미래 예측과 분리한다. [SciPy Theil–Sen 설명](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.theilslopes.html).
- 공간: 동일 학교급·지역에서 3km 내 최대 8개 최근접 이웃을 행 표준화한다. 이웃 없는 기관은 제외. 전역 Moran I는 편차의 공간 교차곱을 편차 제곱합으로 나눈 값이며, 499회 전체 값 순열·기대값 −1/(n−1)으로부터의 절대 편차로 탐색 p를 계산한다. 국소 I는 인구분산 기준 표준화값 z_i와 이웃 평균 z의 곱이다. 자신의 값을 고정하고 나머지 기관에서 이웃 수만큼 중복 없이 499회 추출하며 조건부 기대값 −z_i²/(n−1)에서의 편차를 비교한다. 지도 내 BH q≤0.05일 때만 HH·LL·HL·LH를 표시한다. 여러 질문 간 보정·공간 교란·도로 장벽 보정은 하지 않는다. seed=20260910, JS LCG 난수로 재현한다. [PySAL 조건부 공간 순열 설명](https://pysal.org/esda/stable/user-guide/local_spatial_autocorrelation.html). PySAL의 표본분산 정규화 수치를 그대로 복제한 구현이라고 주장하지 않는다.
- 네트워크·도로 중단: 기존 `designation_diffusion.json`, `road_resilience.json`의 검증된 사전 계산을 조회한다. 가정한 확산은 실제 도입 효과와 구분한다. 세부는 `network_analysis_methods.md` 참조.

## 도서관 접근·후보 계산

2024 공공도서관 건립·운영 매뉴얼 인쇄 38쪽(PDF 52쪽)의 입지선정 표를 렌더링해 확인했다. 도시 1·2km, 농어촌 1.5·2.5km 접근권역을 제시한다. 500m는 기존 앱 비교 조건으로 추가했다. 실제 도보시간·안전 통행·학업 효과를 나타내는 거리는 아니다. 공공·어린이 도서관 82곳을 기본 공급으로, 작은도서관을 포함한 252곳을 별도 조건으로 사용한다.

기존 공개 1km 연령 인구를 인천의 1세별 구성으로 분리하고 100m 총인구 비중으로 배분한다. 연령대는 유치원 3~5, 초등 6~11, 중등 12~14, 고등 15~17세. 100m 중심점이 거리권에 드는지를 계산하며 경계에서 약 70.7m의 위치 근사 여지가 있다. 기존 면적교차 수요와 같은 정의로 취급하지 않는다.

원 인구 파일은 인천 주변 시외 지역도 포함하므로, 전체 1km 배분 분모를 유지한 채 인천 경계 안 중심점으로 집계 범위를 제한했다. 인천시 ArcGIS 경계 서비스는 404여서 기존 보행망 구축 때 확보한 OpenStreetMap relation 2297419를 사용했다. 공식·최신 행정경계로 주장하지 않으며 ODbL 출처를 표시한다. 전체 53,134개 인구 격자 중 25,050개 중심점이 이 경계 안이다.

양의 인구를 가진 250m 격자의 중심이 인천 경계 안인 7,304곳을 검토 후보로 삼는다. 공원 후보에 한정하지 않는다. 후보마다 현재 같은 반경의 도서관 권역 밖에 있는 연령 인구만 신규 도달 수요로 합산한다. 한 후보 안에서는 중복 공급을 제거하지만 후보 여러 곳의 수요는 합산할 수 없다. 수요 결측이 포함되면 전체 수요를 null로 유지한다. 신규 영역에 결측이 없으면 그 영역의 값은 산출 가능하다. 도로·필지·토지 소유·수면·용도규제·운영비 검토 전 후보이며 실제 신규 이용자가 아니다. 인천 밖 도서관은 미반영되어 경계 주변 공급을 과소평가할 수 있다.

거리 5개×공급 범위 2개의 전체 결과는 `library_access_scenarios.json`, 화면은 학교별 거리·연령 수요와 조건별 상위 100개를 담은 `library_access_preview.json`을 사용한다. 상위 후보 정렬은 신규 도달 인구 내림차순이며 결측을 0으로 채우지 않는다.

## 학원 밀집

[DBSCAN 원 논문](https://www.cs.sfu.ca/~ester/papers/kdd_96.pdf)을 근거로 공개 학원·교습소의 밀도 기반 군집을 계산한다. 학원가의 공인 거리·최소 개수 기준은 확보하지 못했다. 200·300·500m와 최소 5·10개를 탐색 조건으로 공개한다. 기본 화면은 300m/10개이며 공인 학원가 경계가 아니다.

2026-08-01 원자료 6,839시설 중 좌표 확보 6,810시설. 같은 건물의 별도 등록 시설도 각각 계산하므로 동일 좌표 지점 수를 병기한다. 경계는 구성 시설의 100m 원 합집합이며 실제 상권 경계가 아니다. 시설 수/표시 면적 밀도와 학교 중심 500m 원면적당 밀도를 구분한다. 대상 분류와 예체능은 기존 공개 교습과정 근거를 유지하며 미확인을 임의 분류하지 않는다. 군집은 연쇄 연결되므로 연결 반경보다 넓어질 수 있다.
