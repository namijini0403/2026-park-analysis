# 전체 통계와 사용자 첨부 교차 분석

## 사용 흐름

질문 범위에서 전체 통계를 선택하면 학교 선택 없이 분석할 수 있다. 질문에 전체·군구별·학교급별을 쓰면 기존에 선택한 학교 필터도 해제한다. 명시한 학교 이름의 질문은 해당 학교를 우선한다.

예: 전체 초등학교 학생 수 군구별 통계 / 학교급별 전체 학생 수 통계 / 학교급별 학생 수와 공원 수의 상관관계.

질문 입력창 위의 내 자료 첨부에서 CSV·TSV·XLSX를 선택한다. 첫 행은 중복되지 않는 열 이름이어야 한다. 엑셀은 시트를 선택할 수 있다. 연결 기준(학교 ID·정식 학교명·군구), 연결 열, 분석 열, 연도 열 또는 기준연도, 기존 지표를 확인하고 질문한다. 가상 예시 CSV를 내려받아 연결을 시험할 수 있다.

## 분석 방식

- 숫자 × 숫자: 학교급과 연도를 분리해 Pearson·Spearman 계수, 유효 쌍 수, 산점도 제공. 최소 3쌍 미만 또는 값이 일정하면 계수 계산 보류.
- 범주 × 숫자: 범주별 기존 값 평균과 건수. 숫자 × 기존 범주: 범주별 첨부 값 평균. 범주 × 범주: 교차 빈도.
- 동일 대상·연도의 중복 행은 모두 제외. 자동 합산·임의 평균·여러 학교로의 중복 연결을 하지 않음.
- 학교명이 유일하게 연결되지 않으면 미연결/중복 상태 표시. 숫자 형식 오류·기준연도 차이·기존 값 결측·학교급 범위 제외를 개별 행으로 표시.
- 군구 연결은 한 학교급을 선택해야 하며, 기존 지표는 해당 군구 학교들의 유효 관측 평균. 지역 총합과 구분.
- 장서 공시는 현재 2025년 자료이므로 같은 연도로 연결. 연도 없는 환경 지표는 스냅샷이라고 명시.
- 전체 통계도 학교급·단위·시점·지표를 섞어 하나의 평균/상관계수로 만들지 않음.

## 자료 취급과 한도

첨부는 브라우저 메모리에 유지한다. 질문할 때 선택한 연결·분석·연도 열만 분석 서버로 전송한다. 모델 프롬프트로 보내지 않고 서버에서 계산하며, 서버 저장·공공 원장 변경·별도 업로드 색인 생성은 하지 않는다. 첨부 제거 이후 질문에는 전송하지 않는다. 이전 답변의 결과는 현재 탭의 대화에 남고 새로고침하면 사라진다.

파일 2MB, 3,000행·40열. 선택 열의 전송 표 800KB 이내. XLSX 압축 해제 선언 크기 20MB 이내. 수식은 실행하지 않고 저장된 결과 값만 읽는다. 암호화 파일·구형 XLS·PDF는 지원하지 않는다. UTF-8 및 EUC-KR CSV를 읽으며 쉼표/탭/세미콜론 구분자를 인식한다.

결과는 기존 Word·PNG·CSV 저장 기능과 연결했다. 연결 상태 화면 표는 300행까지, CSV는 전체 연결 상태를 포함한다. 사용자 제공 값은 공식 검증 자료와 구분하며, 연결 열을 포함한 정규화 표의 SHA-256과 기존 데이터 출처를 표시한다.

## 구현·검증

- api/_population_answers.js: 전체·학교급·군구 통계, 학교급별 관계 분석.
- api/_joined_analysis.js: 입력 제한, 연결, 중복/결측 처리, 교차 분석. api/chat.js 단일 경로 사용.
- assets/chat-upload.js: CSV/XLSX 읽기, 시트/열 선택, 미리 보기, 필요한 열만 전송, 첨부 제거.
- ExcelJS 4.4.0과 MIT LICENSE를 로컬 assets/vendor/exceljs에 포함. 엑셀 첨부 때만 불러옴.
- tests/test_upload_analysis.cjs: 실제 XLSX 저장 결과 읽기, CSV 따옴표, 데이터 연결·연도·중복·범주·군구, UI 열 선택·전송 최소화·첨부 제거, 전체 학교급 분리.
- 기존 단일 챗봇·안전 조건·결측·레거시 추천 방지 및 지도/차트 DOM 회귀 검사 유지.
