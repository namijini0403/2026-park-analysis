# 대화형 답변 복구 · 2026-09-14

문제: 공개 미리보기는 `hitl-analysis.js`의 변수·가중치 설명 화면을 제공했고, 실제 도구 호출형 `chat-agent.js`는 배포되지 않았다. 대상 Railway 서비스에는 `OPENAI_API_KEY`도 없었다.

## 변경

- 기존 로컬 키를 대상 서비스 환경변수에 연결. 키는 배포 파일이나 검증 보고서에 포함하지 않는다.
- 실제 데이터 조회 → 한국어 해석 → 같은 대화 안의 차트·표. 비중·지도·출처·저장은 접어서 제공한다.
- Responses API의 reasoning 출력 항목을 다음 도구 호출에 함께 전달하고, 마지막 호출은 도구 호출을 종료해 답변을 작성하도록 한다. 잘린 JSON 문자열을 도구 결과로 보내지 않는다. [공식 함수 호출 문서](https://developers.openai.com/api/docs/guides/function-calling)
- 해석 실패·빈 출력 시 실제로 조회한 수치와 표를 보존한다. 조회조차 없으면 성공으로 표시하지 않는다.
- 비중 변경은 기준별 관측 패널 순서와 해석을 갱신한다. 학교 종합점수·투자 순위는 생성하지 않는다. 이용·안전·실행·경로 조건은 비중으로 상쇄하지 않는다.
- 예전 가중 점수 응답은 저장 기록에서 현재 추천으로 복원하지 않는다. PAPS 정의가 상충하는 동안 비교 도구에서 제외한다.
- 누락 값을 막대차트에서 0으로 그리지 않는다. 학교 데이터 파일 `school_priority.csv`를 배포 필수 파일로 추가한다.

## 효율

조회 도구 선택은 `gpt-5.4-mini`, 조회 후 최종 설명과 비중 변경 해석은 `gpt-5.4`로 분리했다. 미니 모델의 서로 다른 관측 목록 혼동 및 변경 전 비중 재언급이 실제 검증에서 발견되어 설명 단계만 상향했다. 공식 모델 사양과 실제 계정 호출로 호환성을 확인했다. [GPT-5.4 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4)

상향 후 로컬 검증: 학구 검토 10곳 답변 약 11초, 비중 변경 답변 약 4초. 비중 변경은 결정론적 재조회 후 짧은 해석 1회이며, 최신 비중 62.5/37.5를 정확히 반영했다. 차트는 조회 수치를 SVG로 렌더링하므로 이미지 생성 API가 필요 없다. 비중 변경 설명은 20초 제한이며 지연 시에도 실제 학교명·수치로 직접 요약한다.

## 검증

- `npm run test:simple`: 기본 화면, 도구, 대화, 저장·복원, 프로필 정책 검사 통과.
- `npm run test:agent`: 빈 출력·응답 오류 복구, 마지막 호출 종료, reasoning 상태 전달, 누락 데이터, 종합점수 미생성, 과거 기록 복원 검사 통과.
- 실제 API: 학구 조정 검토 학교 10개 조회, 공원 수 70 / 학생 수 30 비중 변경 후 한국어 답변과 기준별 차트·표 확인.
- 브라우저 연결이 제공되지 않아 실제 픽셀·모바일 화면 검증은 미완료. 대화 DOM 동작은 jsdom으로 확인했다.
