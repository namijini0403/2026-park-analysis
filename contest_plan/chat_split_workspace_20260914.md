# 자료에 묻기 — 대화와 시각화 분리

- 데스크톱은 대화와 선택 답변 근거를 1:1로 배치. 900px 이하에서는 세로 배치.
- 질문 → AI 변수 후보·이유 제안 → 사용자 변수 선택(추가 조건·자료 첨부) → 분석 요청 → 결과. 제안은 도구 없이 모델 1회 호출, 출력 1,600토큰 한도. 보유 지표 사전으로 후보 ID를 제한하며 PAPS 제외.
- 변수는 질문 조건으로 서버에 전달. 결과에서 선택 조건을 다시 확인 가능.
- 오른쪽에 지도·차트를 한 번만 표시. 이전 답변의 지도·통계 보기 버튼으로 전환. 교체 시 이전 지도 해제.
- 상세 수치 표·출처·다운로드·범위 설정은 펼쳐 보기로 유지.
- 저장 목록과 대화 저장 메뉴에서 삭제 가능. 저장본 삭제는 현재 대화 화면을 지우지 않음. 실패 메시지와 저장 건수 갱신 포함.
- 기존 누락 자료·안전 비상쇄·종합점수 금지·이전 저장 기록 보류 규칙 유지.

검증: chat agent UI, saved conversations, observation restore, profile guardrails 및 agent 회귀 검사. 실제 브라우저 화면 검증은 세션에 연결된 브라우저가 없어 수행하지 못함. 운영 배포는 수행하지 않음.
