# 정책 길잡이: 추가 수집 제안과 첨부 형식 확장

## 변경 결과
- 질문의 문제·선택 변수·실제 분석의 결측/제외 결과를 함께 대조해 추가 근거를 제안한다.
- 독서, 야외활동, 통학·이용 경로, 미래 수요, 돌봄·청소년 지원, 사교육, 환경 노출, 성과 검증, 지원 실행의 9개 근거 요건을 등록했다.
- 현재 보유 자료와 범위 한계 / 추가 필요 자료 / 필요한 이유 / 확보 후 달라질 판단 / 조사 항목과 수집 경로를 함께 제공한다.
- 단순 현황 질문에는 현재 답변과 별개의 추가 정책 검토 제안임을 표시한다. 미확보는 부족으로 바꾸지 않는다.
- 일반 답변·HITL 계획·가중치 결과·첨부 분석·저장 당시 근거에 같은 제안을 연결한다. 질문·결과 JSON과 브라우저 주제 기록에 제안이 함께 남는다.
- 등록된 갱신기는 기존 관리자 인증 및 품질 검사·검토 대기 방식을 유지한다. 자동 경로가 없는 추가 정보는 조사표 CSV·기관 파일 첨부로 연결한다. 이번 구현 검증에서 공용 원천 자료의 수집·갱신은 실행하지 않았다.

## 첨부 지원
|유형|형식|사용 방식|
|---|---|---|
|표|CSV, TSV, XLSX, XLS, JSON, GeoJSON|학교명·학교 ID·군구와 기준연도를 선택해 기존 지표와 연결|
|본문/표 문서|DOCX, HWPX|추출 표 또는 본문 근거 선택|
|본문 문서|HWP 5, TXT, MD, 텍스트 PDF|질문 관련 문단·PDF 페이지를 최대 4구간 인용|

파일 15MB, 연결 표 3,000행·40열, 선택 전송 표 800KB. 문서 전송 본문 780KB, PDF 150페이지. 제목이 첫 행에 있어도 열 이름 행을 선택할 수 있다. JSON은 객체 배열·행 배열·headers/rows, GeoJSON은 속성과 점 좌표를 읽으며 임의 도형 지도 등록은 하지 않는다. 원본 파일을 제거하거나 다른 파일을 선택하면 이전 비동기 읽기 결과를 버린다.

PDF·Word·한글·XLS는 서버에서 메모리 내 추출하며 파일을 별도 영구 저장하지 않는다. 문서는 질문 시 전송되고 이 브라우저의 주제 기록에 선택 자료와 결과가 저장된다. 사용자 문서는 제공기관 검증 자료로 승격하지 않는다. PDF/문서 수치는 자동으로 숫자 표로 추정하지 않는다. 본문 출처에 파일명·페이지/문단·원본 파일 SHA-256을 표시한다.

## 효율과 한계
모델 설정은 유지했다. 수집 제안·표 파싱·결측 대조에는 추가 모델 호출이 없다. 문서 해석은 관련 구간 최대 4개만 기존 근거 요약기에 전달한다. 기존 가중치만 바꿀 때의 브라우저 재계산도 유지한다. 등록 요건과 용어 기반이므로 모든 임의 주제를 추론하는 수집 계획기는 아니다. 일치 항목이 없으면 문제·대상·기간 구체화를 안내한다. 수집 제안만으로 검증 상태나 지원 순서를 바꾸지 않는다.

스캔·이미지 PDF는 OCR 텍스트가 필요하며 암호 문서·구형 DOC는 변환 안내한다. 텍스트 추출이 OCR을 수행하지 않는다는 점과 페이지 콘텐츠 크기 제한은 [pypdf 공식 문서](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)를 확인했다. 서버 추출은 동시 2개·25초·Linux 메모리 제한으로 묶었으며 입력 원문을 로그로 남기지 않는다.

## 배포 격리
직전 검증 운영 릴리스의 복사본에 이번 16개 파일만 반영했다. 모든 수정 파일의 시작 상태가 직전 운영 릴리스와 같음을 확인했다. 최종 배포 ID·상태와 운영 브라우저 결과는 동명 validation JSON에 기록한다.
