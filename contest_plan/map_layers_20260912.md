# 지도 영역별 선택 복원 · 2026-09-12

도보와 경계 / 자연과 놀이 / 배움과 돌봄 / 주거와 개발 / 안전으로 구분한다. 기존 학교·도보·학구 기능을 보존하고 시설 레이어 12개를 선택 표시한다. 선택은 이 브라우저에 저장한다.

축소 지도에서 가까운 점을 화면 격자로 묶고, 확대·이동하면 현재 화면만 다시 그린다. 묶음 숫자는 시설 수이며 정책 점수가 아니다. 구역·점·표의 이름을 누르면 실제 기관과 근거가 열린다. 학원가는 기존 탐색 조건 300m·10곳을 명시하고 소속 학원 목록을 연결한다.

## 자료와 한계

공원 1093, 놀이터 322, 도서관 252, 청소년 방과후아카데미 12, 기타 돌봄 506, 공공 야외체육 25, 학원·교습소 6810, 학원밀집 구역 119, 500세대 이상 아파트 536, 정비사업 198, 착공 행정기록 3521, 사고다발지역 11곳. 좌표 미확보는 지도 제외와 별도로 표시하며 시설 부재가 아니다.

청소년 자료는 방과후아카데미이며 복지시설 전수 목록이 아니다. 공원 자료는 전체 녹지·산림 경계가 아니다. 공사 자료는 계양·미추홀·연수 일부 착공 행정기록으로 현재 공사 여부가 아니다. 정비사업과 단지는 대표점이며 출입구·통행허용·안전 판정에 사용하지 않는다.

사고는 https://www.data.go.kr/data/15029185/standard.do 공식 다운로드 API를 두 페이지 모두 수집(전국 12780건), 인천의 최신 사고연도 2024년 11곳을 사용한다. 데이터 기준일 2025-09-24. 관리번호는 배치 번호로 중복되므로 관리번호+연도+유형+위치코드로 식별한다. 공식 위경도 중심을 표시하며, 폴리곤 좌표계가 명시되지 않아 경계는 추정하지 않는다. 현재 위험도나 학교 안전 판정이 아니다.

## 재현

`python scripts/fetch_map_accidents.py`로 공식 사고자료 수집·검증, `python scripts/build_map_layers.py`로 지도 파일을 재생성한다. map_layers/manifest.json에 모든 입력 파일 SHA256과 건수·범위·좌표 제외 수를 기록한다. 현재는 배포 시 재생성하는 지도 스냅샷이다.

## 검증

기존 test_school_map.cjs 통과. verify_map_layers_browser.cjs는 실제 Kakao 지도에서 선택·묶음·표·팝업·학원 소속 목록·선택 복원·모바일·지연응답 해제를 검증한다. outputs/map_layers_20260912에 배포 격리본과 원본 백업·해시·화면·검증 기록을 보관한다.
