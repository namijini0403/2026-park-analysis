# 질문 기반 데이터 분석과 보고서

앱의 기본 흐름은 학교의 사실과 확인 조건을 살펴본 뒤 질문하는 것이다. 기존 분석 화면을 다시 늘리지 않고 챗봇 왼쪽에는 답변, 오른쪽에는 해당 질문의 지도와 도표 및 출처를 표시한다.

## 연결 범위

`api/_data_catalog.js`가 현재 42개 자료 묶음의 원장이다. 공원과 놀이시설, 도서관과 장서, 돌봄과 운동시설, 학원, 공사와 유흥시설, 재개발과 아파트, 공원 공유, 보행과 출입구 검토, 도로 중단, 주거 통행, 학교와 격자 인구, 학교 예측과 진급 시나리오, 지역 인구와 예측 검증, 진학과 운동부 및 대회 기록, 공동교육과정과 연결망, 학교 공시, 유사학교, 지정사업, 통학구역과 도달권을 연결한다.

원본 공시 파일, 정규화 중간 파일, 이전 모형 버전과 과거 순위 산출물은 현재 자료 묶음과 구분한다. 과거 종합점수·추천 순위·자동 행동 결정값을 일반 질의 결과에 복원하지 않는다. 연결 검사 결과는 `data_chat_validation_20260912.json`에 각 묶음별로 기록한다.

## 질문과 처리

| 질문 예시 | 결과 |
|---|---|
| 보유 데이터와 분석 목록 보여줘 | 질문으로 열 수 있는 자료 목록 |
| 남동구 공원 목록 보여줘 | 해당 지역 시설 지도와 표 |
| 2025 초등학교 학생 수 자료 보여줘 | 공시연도를 고정한 관측 표 |
| 이 학교 미래 학생 수 전망 보여줘 | 실제 관측과 모형 예측을 구분한 선 그래프 |
| 2026 고등학교 장학금 금액과 학생 수 상관관계 | 학교 ID와 연도를 연결한 새 분석과 산점도 |
| 학원 밀집 분석 보여줘 | 기존 DBSCAN 계산 지도와 한계 |
| 도로 중단 시나리오 보여줘 | 기존 대체 경로 검사의 조건별 집계 |
| 공동교육과정 연결망 자료 보여줘 | 공고에 근거한 제공·참여 가능 학교 관계선 |
| 이 학교 유사학교 자료 보여줘 | 현재 확장 학교급의 비교군 관측 표 |

질의는 등록된 자료와 허용된 계산으로만 처리한다. 임의 코드나 SQL을 실행하거나 관측값을 생성하지 않는다. 정규화 원장은 파일 수정시간을 기준으로 캐시한다. 단순 조회와 계산은 LLM 호출 없이 수행하고, 해석·정책 시사점을 명시적으로 요청하면 작은 근거 묶음으로 기존 AI 설명 경로를 사용한다.

공시 지표의 새 관계 분석은 같은 학교 ID·공시연도에 일대일 연결된 값만 사용한다. 중복과 결측은 제외한다. 다른 학교급·연도·측정 단위 또는 실제 관측과 예측이 섞인 수치의 전체 평균은 제시하지 않는다. 시설의 대표점이나 직선 500m는 출입구 접근성 확인이 아니다.

## 저장

- Word DOCX: 질문, 답변, 시각자료, 표, 한계와 출처·해시를 담는다. Word 라이브러리는 클릭 시에만 로드한다.
- PNG: 답변과 시각자료, 한계, 출처를 보고서 이미지로 저장한다. 지도는 같은 좌표와 경계·경로를 사용하는 보고서용 위치도로 만든다. 외부 배경 타일은 포함하지 않으며 파일에 이를 명시한다.
- CSV: 필터된 전체 표를 저장한다. 화면과 Word 표는 최대 1,500행이며 집계는 필터된 전체 자료를 사용한다. 크기 제한은 결과에 명시한다.

내보내기는 브라우저 안에서 수행하며 추가 AI 요청이나 문서 업로드를 하지 않는다.

## 검증과 운영 상태

`npm run test:simple`

`node tests/test_chat_workspace.cjs`

`node tests/test_data_catalog.cjs`

`node tests/test_answer_export.cjs`는 임시 QA 경로의 `@napi-rs/canvas`로 앱의 실제 내보내기 함수를 실행한다. PNG와 DOCX 생성 후 DOCX를 LibreOffice와 문서 스킬 렌더러로 페이지 이미지로 변환하여 확인했다. QA 파일은 `outputs/chat_report_qa/`에만 둔다.

빌드는 모든 등록 원장을 정적 출처 링크 경로로 복사한다. 서버리스 포함 파일에도 등록 원장을 명시한다. 운영 배포는 하지 않았다. 연결된 브라우저가 없어 앱 전체의 픽셀 검수는 미실시했으며 실제 Leaflet DOM 검사와 보고서 렌더링 검사로 확인했다.
