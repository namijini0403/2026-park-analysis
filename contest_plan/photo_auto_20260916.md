# 학교 사진 자동 표시

- 학교 프로필을 선택하면 사진 검색을 비동기로 시작한다. 학교 분석 렌더링은 기다리지 않는다.
- Google 검색 결과는 최대 3개의 이름·주소·사진 미리보기 카드로 표시한다. 검색 결과 순서는 장소의 확정이나 정책 판단을 뜻하지 않는다. 여러 후보 중 하나를 자동 선택하지 않는다.
- 검색 카드만으로는 사진이 표시되지 않는 경우가 있어, 각 후보에 기존 Place Details 미디어 위젯을 붙인다. 이름·주소·Google 출처 표시는 제공자 위젯을 유지한다. 사진에는 무관한 장소나 과거 사진이 포함될 수 있음을 안내한다.
- 주변 시설은 목록 선택만으로 사진을 요청하지 않는다. 사진 찾아보기를 눌렀을 때 조회한다. 학교로 돌아오면 다시 자동 조회한다.
- 학교 전환·동일 DOM 재사용 시 이전 응답을 무시한다. 같은 검색 위젯의 반복 load는 사진 카드를 재생성하지 않는다. SDK 연결은 현재 페이지에서 재사용한다.
- 사진 서비스 미연결·오류·자료 없음은 사진 영역에서 표시하고 재시도할 수 있다. 사진 미확보를 시설 부족으로 해석하지 않는다.

공식 위젯 동작 참고: https://developers.google.com/maps/documentation/javascript/reference/places-widget

## 검증

- `node tests/test_school_photos.cjs`: 자동 학교 요청, 시설 수동 요청, 복수 후보 미확정, 명시적 선택, 오래된 응답·이벤트 격리, SDK 재사용, 실패 재시도, HTML 이스케이프, 반복 load 재사용.
- `npm run test:simple`: 기존 학교 UI·챗봇·과거 추천 복원 방지·프로필 회귀 통과.
- `tests/verify_photo_auto.cjs`: 운영 도메인에서 변경 JS만 대체한 사전 검증으로 Google 사진 미리보기·수동 시설 검색·학교 재선택·390px 모바일 확인. 제공자 미디어는 배경 이미지로 표시되므로 일반 img 태그만 검사하지 않고 실제 사진 열기 컨트롤과 화면을 함께 확인했다.
- `outputs/photo-auto-20260916/`에 화면과 검증 기록 저장.
