## 검증 범위

- 지정 전파 검사 3개: 사슬·고립 노드, 확률 0/1, 1회 전파 시도, 재현성.
- 공유 배분 검사 4개: 자원 보존·공원 손실, 연결된 결측 수요·미확정 면적, 공원 없음·0명 분모.
- 공동교육과정 검사 3개: 원문 전체 364강좌, 이미지로 확인한 병합 셀, 중복·자기 연결 배제와 시뮬레이션 범위.
- 현장 확인 검사 2개: 학교급별 평균 동점 백분위, 결측과 공급 감소 시 우선순위 변화 방향.
- 도로 중단 검사 2개: 다른 공원 대안, 거리 제한, 무방향 구간 제거와 우회.
- 도로 결과 전체 917개 상태·기초 거리 상한·구간 수·추가 거리 비음수 및 입력 그래프 해시 확인. 현장 확인 입력 해시도 확인.
- `tests/test_education_networks.cjs`: 실제 JSON의 유치원 369개, 중학교·강화군 필터, 거리 반경 변경, 공동교육과정 확률·학교 전환, 현장 확인 공원 전환, 고등학교 도로 분석 129개 범위, NaN 미표시. JSDOM은 실제 브라우저 렌더링을 증명하지 않는다.

## 남은 작업과 차단 근거

새 통계창을 실제 브라우저에서 열어 표·선택기·곡선·스크롤 배치를 확인해야 한다. 2026-09-10 세 차례 연속 목표 턴의 CUA 조회 모두 `apps: [], browsers: []`였다. 마지막 턴에서도 callable tool 목록에 Playwright·대체 브라우저 도구가 없음을 재확인했다. 추가 계산이나 배포 반복으로 해소할 수 없는 상태이므로 목표를 차단 상태로 전환한다. 연결 가능한 브라우저가 생기면 배포 사이트에서 인증번호 2026으로 진입해 전체 통계를 열고 위 제어를 확인한다.

이 차단을 분석 자료 부재로 혼동하지 않는다. 원문 수집·계산·통계창 코드·모의 조작 검증까지 완료했으며, 현재의 미완료 범위는 실제 렌더링 검증이다.
