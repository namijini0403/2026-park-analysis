# 전체 통계 시각화 개선 · 2026-09-14

## 화면
- 05 영역별 통계: 한 지표 선택 → 핵심 수치 → 전체 분포 → 군구별 비교.
- 중앙값, 중간 50% 구간, 자료 확보/대상 학교 수를 먼저 표시.
- 실제 최소~최대 선 위에 사분위 띠·중앙값 선·평균 점·선택 학교 마커.
- 군구는 이름순, 공통 축. 수치별 순위나 종합점수로 변경하지 않음.
- 일반지역과 강화·옹진을 전환하며 분모와 선택 마커도 같은 범위로 제한.
- 정확한 수치표, 미확보 사유, 사분위 계산법은 접어서 제공.
- 챗봇: 일반 막대를 점그래프로, 산점도와 시계열 축/결측/예측 표시 개선. 구간 빈도는 막대 유지.

## 정확성
- 전체·도서·군구마다 n/mean/median/min/max/q1/q3 제공.
- 미확보는 0 또는 표본에 포함하지 않음. 동일값은 한 구간. 백분위는 동점 중간 위치.
- PAPS 정의 불일치 지표는 비교에서 제외.
- 예측 표시값을 관측값으로 설명하지 않음.
- 별도 모델, ImageGen, 외부 차트 라이브러리 또는 추가 LLM 호출 없음.
