# 질문과 근거를 함께 보는 챗봇

- 데스크톱: 왼쪽 답변·질문, 오른쪽 해당 답변의 지도·차트·표·하단 출처. 작은 화면에서는 답변 다음에 자료를 배치한다.
- 이전 답변의 `지도·자료 다시 보기`로 해당 자료를 다시 연다. 근거 없는 답변은 이전 자료를 남기지 않는다.
- `2026 연구학교, 선도학교 목록 보여줘`: 수집한 공식 원장 기준 108개 학교, 116건. 지도는 정확히 학교 원장과 연결되고 좌표가 확보된 103개교. 나머지 5개교도 표에 포함한다. 학교급을 명시하지 않으면 모든 학교급을 조회하며, 상단에서 선택한 학교급으로 몰래 제한하지 않는다.
- 지정 유형별 학교 수는 중복을 허용한다. 당일 운영 여부·전체 사업 완전성은 확정하지 않고 학년도와 수집 기준을 명시한다. 새 자료를 웹에서 실시간 수집하는 기능은 아니다.
- 상관관계·추세·분포·지역 차이·공간 군집을 각각 산점도·선·로렌츠곡선·상자그림·지도로 표현한다. 서버 계산 해석과 조건·한계를 함께 제공한다. 관측값을 표로도 제공한다.
- 개별 학교 예측은 실제 관측과 예측을 구분하며 예측 구간을 점선으로 표시한다. 주변 시설의 좌표가 있으면 학교와 함께 표시한다. 지도 위치는 출입구 접근성 검증이 아니다.
- 단순 목록·통계는 기존 서버 원장·계산 결과를 그대로 사용하며 추가 LLM 호출이 없다. 일반 근거 답변은 기존 RAG 경로를 유지한다. 임의 모델 HTML을 실행하지 않는다.

실제 Leaflet을 사용하는 DOM 검사에서 마커 수·표·원문 링크·5개 차트 유형·예측 구분·과거 자료 복원·자료 초기화·HTML escaping을 확인했다. 로컬 HTTP 결과는 `chat_workspace_validation_20260912.json`에 보관했다.

로컬 미리보기: http://localhost:3088. 운영 배포는 하지 않았다. 연결된 브라우저가 없어 픽셀 단위 시각 검수는 미실시했다. 지도 배경은 OpenStreetMap 네트워크 연결이 필요하며 연결 실패 시 안내와 표를 유지한다.
