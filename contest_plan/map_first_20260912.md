# 지도에서 시작하는 HITL — 2026-09-12

## 구현

- 학교 원장 917곳(유치원 369, 초등 272, 중학교 147, 고등학교 129)의 좌표를 학교 요약 API 목록에 추가했다. 수치 원자료는 변경하지 않았다.
- 학교급은 독립 체크 버튼이며 복수 선택은 합집합이다. 전부 해제할 수도 있고 ‘모두 선택’으로 복원할 수 있다. 검색과 지도·목록이 같은 집합을 사용한다.
- 지도 위치 또는 검색 목록에서 학교를 선택하면 기존 사실·조건·선택지와 검토 기록에 연결된다. 동일 좌표의 학교는 점선 마커의 선택 목록으로 각각 확인한다.
- 500m는 학교 대표점 기준 직선 반경이다. 공식 학구도는 `school_zones.geojson`의 연결 학교 ID로 선택한다. 점의 경계 포함 여부나 거리로 배정 학교를 추정하지 않는다.
- 학교 미선택 시 선택 학교급의 학구도를 보여준다. 선택 시 해당 학교와 공식 연결된 학구만 표시한다. 반경과 학구는 독립적으로 켜고 끈다. 공동 학구·다중 연결을 단일 학교에 억지로 합치지 않는다.
- 학구도는 초등 279, 중등 25, 고등 7개, 총 311개이다. 현재 자료 기준 2026-03-20. 유치원 경계는 미제공으로 명시한다. 연결 실패·미연결도 경계가 없다는 의미로 바꾸지 않는다.
- 초기 지도는 인천 시가지 중심이다. ‘도서지역 포함 전체 보기’는 현재 필터의 모든 좌표 범위를 보여준다. 선택 학교의 학구 전체 보기로 큰 구역도 확인한다.
- 모바일에서는 학교급 버튼을 유지하고 검색·경계 설정은 펼쳐서 본다. 지도 필터와 전체 질문의 학교급은 별도이며 화면에 그 범위를 안내한다.
