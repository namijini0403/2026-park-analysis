# 정책 길잡이 · 출처 연결 강화

대화형 분석 도구를 ‘정책 길잡이’로 명명했다. 자료 해석·학교 비교·정책 검토 방향을 함께 찾는 역할을 화면에 설명한다.

답변마다 S1… 출처 카드를 붙인다. 원본/제공 페이지 URL, 자료 기준일, 수집일, 수집 원본 보관 경로(확보 시), 실제 분석 파일과 기존 SHA256·학교/행 식별자를 구분한다. 원본 경로가 없는 자료는 원본 미확보로 안내한다. 사용자 첨부는 기관 검증 자료와 구분한다.

원본 URL은 data_sources.yaml과 49개 입력 파일에 기록된 메타데이터에서 수집한다. 자료집의 원문 목록이며 개별 주장과 모든 링크의 일대일 대응을 보장하지 않는다. 이 범위를 UI에 명시한다. 출처 응답은 8개 URL까지 보내고 전체 목록 JSON을 연결한다. 사용자 첨부·공원 원문 누락·데이터 변경을 임의 기관 링크로 보완하지 않는다. 장서 지표는 공유 자료집의 돌봄/체육 원문을 잘못 인용하지 않도록 별도 연결한다.

일반 답변·가중치 결론·주제별 저장/복원·Word/PNG/JSON 저장에 동일 출처 체계를 사용한다. 별도 LLM 호출 없이 기존 결과를 보강하며, 출처 메타데이터는 파일 변경시각으로 캐시한다. 입력 파일 SHA256이 바뀌면 이전 출처 레지스트리를 현재 값에 붙이지 않고 재확인 안내한다.

재생성: node scripts/build_source_provenance.cjs. 입력 자료가 갱신되면 함께 재생성·배포한다. 출력은 data_processed/source_provenance이며 비공개 자료 원문을 새로 공개하지 않는다. 공개 원문 URL에 인증키·토큰이 있으면 제외한다.

검증: test_source_provenance.cjs, test_answer_export.cjs, test_question_levers.cjs, test_observation_restore.cjs 통과. 실제 브라우저 검증은 일반 답변 원본 URL·기준일, JSON 저장, 가중치 결론, 모바일, 주제 복원을 포함한다. 인천교육청 학원 원문·도서관 표준데이터·학구도 제공 페이지의 HTTP 200 확인. outputs/policy_guide_20260912에 원본 백업/배포 해시/화면/검증을 보관한다.
