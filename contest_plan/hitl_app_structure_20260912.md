# 반경너머 HITL 앱 정리 — 2026-09-12

기준: workspace `beyond_radius_hitl_architecture.md` v2와 실제 작업 폴더 `park-railway-deploy`. 설계 문서가 검토한 과거 main과 로컬 구현은 다르다. 기존 변경을 보존하고 기본 진입점과 화면 자산만 정리했다.

## 제품 흐름과 이번 구현

**학교 살펴보기 → 자료에 질문하기 → 검토 기록**. 세 화면 중 하나만 표시하며 언제든 이동한다. 선택 학교와 자원을 상단에 유지한다.

- 학교: 기존 서버 요약으로 확인된 사실 / 더 확인할 조건 / 검토할 선택지를 표시한다. 점수·자동 선택·학교 순위는 만들지 않는다.
- 질문: 기존 단일 API, 지도·표·차트·출처·첨부 기능을 보존한다. 질문 예시와 첨부 열 설정은 펼쳐서 본다. 실제 질문 범위는 별도 선택하고 문장으로 표시한다.
- 기록: 검토 목적과 이유를 필수로 입력하고, 보류 / 조건 확인 진행 / 여러 선택지 계속 검토 중 하나를 기록한다. 선택지 메모와 후속 확인을 추가할 수 있다. 이는 정책 승인이나 검증 완료 표시가 아니다.
- 저장: 작성 시각, 학교·자원, 현재 관측 요약, 미확인 조건, 원자료 해시와 메모를 JSON에 함께 담는다. 학교·자원 변경 때 초안을 비워 다른 대상에 잘못 저장하지 않는다. 저장 전 화면 유지에 한하며 새로고침 후 복원하지 않는다.
- 기술 정보와 구현 범위는 접힌 상세 영역에서 확인한다. 채팅·첨부는 검토 파일에 자동 포함되지 않으며, 답변별 기존 저장 기능을 사용한다.

성공 기준: 첫 화면에 세 가지 작업이 겹치지 않고, 근거 없는 확정이나 우선순위를 추가하지 않으며, 어떤 관측을 보고 보류했는지 파일에서 확인할 수 있다.

## 설계 문서 대비 실제 구현 경계

| 영역 | 기존 로컬 구현과 근거 파일 | 이번 작업 / 추가 작업 |
|---|---|---|
| 학교·자원 관측 | `api/_school_summary.js`: 서버 원장, 부분·결측 안내, 도서지역 별도 검토, 출처 해시 | 이번: 전용 조회 화면. 추가: 학교 선택 연동 탐색 지도 |
| 질문·공간 근거 | `api/chat.js`, `assets/chat-workspace.js`: 질문별 계산·지도·표·차트·근거 | 이번: 독립 작업 화면과 범위 안내. 기존 해설을 공식 정책 실행으로 확장하지 않음 |
| 사용자 표 | `assets/chat-upload.js`, `api/_joined_analysis.js`: CSV/Excel 연결·분석 | 기존 유지. 추가: 정책 기준·시행 조건으로의 의미 해석, 시나리오 재계산, 분석별 영속 버전 |
| 교육청 문서 | `api/_office_documents.js`, `office-documents.html`: 별도 문서 분석 경로 | 기존 유지. 모든 문서가 정책 제약으로 자동 연결된 것은 아님 |
| 공개자료 갱신 | `scripts/update_center/{scheduler,automatic,pipeline}.mjs`: 등록 출처 수집·검사·반영 경로 | 과거 설계의 staging-only 단계보다 진행됨. 이번 원격 갱신·운영 검증은 실행하지 않음 |
| 후보·예측 | 기존 분석 산출물과 별도 계산 코드 보유 | 사용자 원칙에 맞는 공통 정책 비교 엔진 완성으로 간주하지 않음 |
| 사람의 기록 | 기존 답변·근거 내보내기 | 이번: 학교 요약에 고정한 검토 메모. 추가: 담당자 인증, 공용 이력, 불변 실행 스냅샷 |
| 지원안 비교 | 목표·예산·실행 제약을 함께 검증하는 공통 실행 경로 미완성 | 추가: 명시적 정책 목표 아래 실행 가능한 대안 2~3개 비교와 조건 변경 전후 차이 |

`자동 갱신 구현` 문서의 과거 운영 검증 기록은 이번 테스트 결과와 구분한다. 모든 출처가 자동화됐다고 표시하지 않는다. 현재 지도는 질문 결과의 근거 지도다. 설계안의 지도 중심 진입은 추후 학교 선택 연동 지도로 연결하며 이번에는 기존 기능을 중복 작성하지 않았다.

## 다음 작업 순서와 완료 조건

1. **도서관 검토 조건과 실행 기록**: 장서·학생수·기준연도를 연결하고 담당자가 기준과 근거를 채택한다. 기준 미선택·필수 관측 결측은 계산 보류. 학교별 종합점수 없음.
2. **대안 비교와 현장 수정**: 자격·안전·실행·출입구 경로의 근거가 있는 대안만 비교한다. 예산·비용 미확보는 임의 수치로 대체하지 않는다. 수정 전후 조건·관측 변화가 구분돼야 완료.
3. **실행 재현과 공용 기록**: 자료 스냅샷·정책 팩 버전·계산 조건·사용자 근거를 연결하고 기록 재생성 검증. 인증된 담당자의 공식 결정은 이 단계에서 별도 구현.
4. **자료 갱신 영향 연결**: 현재 파일 diff를 정책 실행 변화와 연결. 같은 정책 조건에서 새 자료 적용 전후의 보류·대안 변화를 확인하고 롤백 재현.

새 엔진·서비스나 AI 모듈을 한꺼번에 추가하지 않는다. 현재 검토 메모를 정식 실행 재현성이나 정책 승인 기능으로 소개하지 않는다.

## 검증

- `npm run test:hitl`: 한 화면 표시, 학교 미선택 저장 차단, 목적·사유 필수, 요약·해시 내보내기, 과거 추천 미복원, 학교·자원 변경 초안 초기화.
- `npm run test:simple`: 기존 학교 화면·챗봇·미확보·도서지역·안전 게이트·점수 미노출·낡은 추천 복원 방지.
- `npm run test:analysis`: 기존 결정론적 계산과 API·질문 해석·범위 제한.
- `node tests/test_chat_workspace.cjs`: 실제 자료 기반 지도 요소·표·차트·출처·답변 이력.
- `node tests/test_upload_analysis.cjs`: 첨부 분석의 연결·결측·범위 계약.
- `npm run build:vercel`: 기본 화면과 정적 자산 빌드.

브라우저 도구의 연결 목록이 비어 있어 실제 브라우저 시각 검수는 수행하지 못했다. DOM 동작 검사와 CSS 반응형 규칙 확인을 시각 검수로 대체했다고 주장하지 않는다. 운영 배포는 수행하지 않았다.
