# 선택 변수 표·시각화 연동 (2026-09-16)

챗봇 근거 영역의 학교·지역 행 표에서 변수를 선택하면 동일한 행과 수치로 비교 그래프와 수치 표를 동시에 표시한다. 별도 모델 호출이나 외부 시각화 API 없이 받은 응답을 브라우저에서 표시한다.

- 기본 3개, 최대 4개 숫자 변수를 선택한다. 각 열은 독립된 0 기준 눈금이며 합성 점수·지원 순위를 만들지 않는다.
- 10행 단위로 그래프와 표가 함께 이동한다. 모든 페이지에 동일한 열 눈금을 적용하고 원래 행 순서를 유지한다.
- 숫자 타입만 관측값으로 표시하며 null/문자 결측을 0으로 바꾸지 않는다.
- 행마다 단위가 다른 지표 프로필·상관 요약에는 적용하지 않는다. 등급·PAPS·점수·연도는 자동 비교 변수에서 제외한다.
- 원본 전체 표는 접어서 보존한다. 선택하지 않은 열과 출처 링크를 모두 다시 확인할 수 있다.
- 모바일은 그래프 내부 가로스크롤을 사용한다.

검증: tests/verify_table_comparison.cjs (선택 연동, 0/결측, 페이지, 4개 한도, 혼합단위 제외, 원본 출처 링크, 모바일), tests/verify_table_comparison_live.cjs (실제 query_schools 반환 학교 자료 + 현재 앱 CSS), npm run test:simple 통과.

실제 응답 데이터 검증은 서버 도구 query_schools를 직접 호출한 것으로, LLM 답변 문장과 표의 학교 선정 일치까지 보장하는 검증은 아니다. 원본 응답의 조회 범위 안내와 출처는 유지한다.
