# 질문형 분석·도서관·학원 밀집 확장

## 완료 조건 (원래 요청 범위 유지)

1. 자연어 질문을 데이터 구조에 맞는 실행 가능한 분석 계획으로 변환한다. AI API 연결과 키 없는 검증 경로를 모두 제공한다. 계산은 허용된 분석 코드가 수행하고 AI가 수치를 만들지 않는다.
2. 관계·조건별 차이·공간 군집·격차·변화·네트워크 질문을 지원하고, 자료가 불충분하면 원인과 가능한 대안을 표시한다. 조건 보정·표본·결측·시간 정렬을 계획과 결과에 남긴다.
3. 분석 인사이트에서 질문 입력, 읽기 쉬운 답변, 적합한 차트·지도, 조건 변경, 근거 및 재현 가능한 분석 기록을 제공한다.
4. 도서관 거리 근거를 확보하고 500m 밖 접근권역을 비교한다. 격자별 수요와 기존 공급 중복을 반영한 추천 후보를 미리 계산한다. 시설 종류·거리 가정·실제 이용 영향의 차이를 표시한다.
5. 유치원·초등·중등·고등 학생수 증감과 각 연령대 격자 수요를 검증하고 분석 및 추천에 연결한다. 재학생 수·거주 인구·미래 시나리오는 구분한다.
6. 학원 밀집 지표의 근거를 조사하고, 근거가 있는 범위에서 밀집 구역·대상 및 과목 성격을 제공한다. 공인 학원가 경계가 아니면 그렇게 표시하며 매개변수 민감도를 공개한다.
7. 실제 입력·계산·API·화면 동작을 검증하고 GitHub 푸시·미리보기 배포를 수행한다. 실제 브라우저 시각 검증 여부를 별도로 기록한다.

## 조사·설계 결정

- 2024 공공도서관 건립·운영 매뉴얼: 경남교육청 공식 게시물(2025-03-06)에 첨부된 원문 확보. PDF 52쪽/인쇄 38쪽의 입지선정 표를 렌더링해 확인했다. 도시 1·2km, 농어촌 1.5·2.5km 접근권역을 제시한다. 거리→시간 환산은 어린이 실제 보행속도를 보장하지 않으므로 앱의 실측시간으로 쓰지 않는다. 공공·어린이 도서관을 기본 공급으로, 작은도서관 포함은 별도 비교한다.
- 원문: https://www.gne.go.kr/component/file/ND_fileDownload.do?q_fileSn=181529718&q_fileId=e51702fc-8a23-405b-a7f0-94d56a7cceef
- 파일·해시: data/context_sources/raw/library_manual_manifest_20260910.json. 검색 도구의 첫 첨부 링크가 기관 설립 안내서로 연결되어 원본 HTML의 파일 ID를 확인해 수정했다.
- 도서관 거리 권역과 격자 인구 중첩은 한국지도학회 2024년 연구도 사용한다: https://doi.org/10.16879/jkca.2024.24.1.059. 본 작업에서는 교육적 인과 효과나 실제 이용률로 해석하지 않는다.
- 기존 학생수 이력·예측은 920개 원장 ID, 앱 환경 분석은 917개 기관이다. 신규 데이터셋은 실제 앱 범위를 사용하며 미편입 3개를 숨기지 않는다.

## 진행 상태

구현·사전 계산·로컬 검증·GitHub 푸시·미리보기 배포 및 실제 HTTP 검증 완료. 결과는 [배포 검증 기록](question_analysis_deployment_20260910.md)에 남겼다.

| 완료 조건 | 구현 및 검증 근거 |
|---|---|
| 질문 → 실행 계획 | `api/analysis.js`: 엄격한 AI 계획 스키마, 키 없는 규칙 기반 경로, 미확보 성과지표 차단. API·계획기 테스트 통과. |
| 분석 기법 | 순위상관·부분순위상관, Cliff's delta, Gini·Lorenz, 공통 기관 코호트 Sen 기울기, Moran I·지역 공간 검정 및 BH 보정, 기존 네트워크 시나리오. 수식 단위 테스트 통과. |
| 질문 화면 | 인사이트 탭 내 질문·예시·조건 변경·SVG·표·근거·기록 다운로드·최근 기록. 실제 데이터와 연결한 JSDOM 동작 검증 통과. |
| 도서관 | 7,304개 250m 후보 × 5개 반경 × 2개 공급 정의. 기존 공급에서 벗어난 연령별 추정 거주 수요를 사전 계산. 경계·중복·결측·배열 정합 검증 통과. |
| 전 학교급 수요 | 실제 앱 917개 기관과 유·초·중·고 4개 연령대. 관측 증감과 공통 코호트 추세, 500m 추정 거주 수요를 연결. 기존 예측과 구분. |
| 학원 밀집 | 좌표가 있는 6,810개 시설, DBSCAN 6개 설정. 기본 300m·10개 설정에서 119개 군집. 대상 분류·예체능·형상 제공, 공인 경계가 아님을 명시. |
| 검증·배포 | 기존 교육 앱 테스트 6개, 신규 분석 테스트 4개, Python 테스트 4건 통과. 정적 SVG 렌더링 확인. 배포 HTTP 검증은 별도 기록. |

실제 브라우저 세션을 제공하는 도구가 없어 전체 화면의 실제 브라우저 시각 검증은 수행하지 못했다. SVG 렌더링과 DOM 동작 검증을 실제 브라우저 검증으로 표현하지 않는다. 외부 유료 AI 요청은 모의 계약 테스트로 검증했으며, 키 없는 실제 데이터 계산 경로와 구분한다.

계산 정의·자료 범위·재현 명령은 [분석 방법 문서](question_analysis_methods.md)에 정리했다.
