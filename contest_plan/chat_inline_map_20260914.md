# 대화 안 지도 표시

- 답변 문장 바로 아래에 독립된 카카오 지도를 표시한다. 이후 질문이 와도 앞선 답변의 지도는 유지한다.
- 학교로 이동, 전체 보기, 학구도·보행 500m 분석 범위 표시 전환을 제공한다. 출입구·통학로가 검증됐다는 의미로 표현하지 않는다.
- 화면 근처 지도부터 불러오고, 새 대화·답변 갱신 때 지도 인스턴스를 정리한다. 실패 시 재시도 버튼을 표시한다.
- 후속 질문에는 앞서 표시한 학교 ID만 추가 전달한다. 경계 좌표를 모델 문맥에 넣거나 지도 표시를 위해 추가 모델을 호출하지 않는다.
- 기존 공개 배포에 이번 변경만 덧씌웠다. 별도 작업 중인 학교 프로필·공통 스타일 수정은 덮어쓰거나 배포하지 않았다.

검증: 지도 독립성·경계 중복 제거·학교 이동·표시 전환·비동기 정리·재시도·대화 회귀 검사 통과. 카카오 SDK는 공개 도메인 Referer로 HTTP 200. 공개 서버 후속 질문에서 같은 학교 10곳과 경계 22개, 답변 내 지도 카드 생성·렌더러 전달을 확인했다(약 6.1초). 연결 가능한 브라우저가 없어 지도 타일·화면 픽셀 검증은 미완료다.
