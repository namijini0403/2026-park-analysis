# update_center/ — 공공데이터 업데이트 센터 (승인 기반 자가진화 설계 스텁, 2026-08-04)

이 문서는 범정부대회 사업계획서(v4)가 약속한 "공공데이터 업데이트 센터"의 설계 스텁이다. **아직 구현되지 않았다.** 실제 자동화 코드는 W3 단계에서 작성한다.

## 왜 "승인 기반"인가

`data_processed/`의 다수 파일(`school_priority.csv`, `parks.csv`, `school_nearest_park.csv` 등)은 CONTEXT.md 봉인 섹션(159행 이후)에 기록된 실측 검증값을 담고 있다. 공공데이터 원본이 갱신되었다고 해서 파이프라인을 무조건 자동 재실행하면 이 봉인값이 재계산으로 덮어써질 수 있다. 따라서 이 업데이트 센터는 "감지 → 자동 재분석 → 자동 반영"이 아니라 **"감지 → 사람 승인 → 샌드박스 재분석 → 사람이 전후 비교 확인 → 승인 시에만 반영"** 흐름으로 설계한다.

## 파이프라인 흐름 (1페이지 요약)

```
1. 감시(watch)
   └ 공공데이터 원본 3~5종의 갱신 여부를 주기적으로 확인
     예: 인천시 공원 현황, 학교 현황(나이스/학교알리미), 인구 통계(통계청 KOSIS),
         재개발구역 고시, 어린이집/유치원 현황
   └ 각 원본은 pipeline/registry/data_registry.yaml의 어떤 dataset(들)을 갱신시키는지
     매핑되어 있어야 함 (현재 registry에는 아직 "원본 출처" 필드가 없음 — W3에서 추가 예정)

2. 품질검사(quality gate)
   └ 원본의 스키마/행수/좌표 유효성 등 1차 검증
   └ registry의 sealed: true 데이터셋에 영향을 주는 원본이면 여기서 플래그 표시하고
     자동 진행을 중단, 사람 승인 대기 상태로 전환

3. 샌드박스 재분석(sandbox re-run)
   └ 운영 data_processed/를 직접 덮어쓰지 않고 격리된 디렉터리에서
     pipeline/core + pipeline/layers/<layer> 파이프라인을 재실행
   └ registry의 generators 체인을 따라 영향받는 다운스트림 파일까지 전부 재계산

4. 전후 비교(diff)
   └ 샌드박스 산출물 vs 기존 운영 산출물을 파일 단위로 비교(행수, 주요 통계, 지도 시각화 스냅샷 등)
   └ sealed 데이터셋은 봉인값과의 편차를 별도로 강조 표시

5. 버전 기록(versioning) + 승인
   └ 비교 리포트를 사람에게 제시 → 승인 시에만 운영 data_processed/에 반영
   └ 반영 이력(원본 갱신일, 재분석 실행일, 승인자, 변경된 파일 목록)을 버전 로그로 남김
   └ registry의 데이터도 이력에 맞춰 갱신
```

## data_registry.yaml과의 연결

이 업데이트 센터는 `pipeline/registry/data_registry.yaml`을 **의존성 그래프**로 사용한다.

- `operating: true`인 데이터셋은 index.html이 실제 로딩하므로 갱신 시 공개 URL 검증(OPERATING_PATHS.md 체크리스트)까지 통과해야 반영 완료로 간주한다.
- `sealed: true`인 데이터셋은 3단계(샌드박스 재분석) 결과가 기존 봉인값과 달라도 **자동 반영하지 않고** 반드시 사람이 CONTEXT.md 봉인 섹션과 대조 후 승인해야 한다.
- `generators` 목록은 "원본 갱신 → 어떤 스크립트들이 재실행 대상인지"를 판단하는 1차 근거로 쓰인다. 다만 registry 자체가 "generators는 읽기/쓰기 미구분 grep 결과"라는 한계를 명시하고 있으므로, 실제 재실행 대상 스크립트 확정은 W3 구현 시 스크립트 본문(`to_csv`/`to_file` 대상 여부)까지 확인해 정밀화해야 한다.

## 레이어 확장과의 관계

도서관 레이어(`pipeline/layers/library/`)가 온보딩되면 이 흐름은 레이어별로 반복 적용된다. 감시 대상 원본, 품질검사 규칙, sealed 플래그는 레이어마다 다르지만 5단계 흐름 자체는 공통이다.
