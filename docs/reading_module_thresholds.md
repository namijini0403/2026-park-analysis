# 독서환경 격차 유형 임계값 근거 (P2 Task 2)

산출 스크립트: `scripts/reading_module/apply_reading_gap_types.py`
대상 데이터: `data_processed/school_library_access.csv` (인천 초등 272개교, Task 1 산출)
수요 조인 데이터: `data_processed/school_enrollment_forecast_20260418_model1.csv`

제출 문서 원문은 각 임계값을 "데이터 분포와 정책기준 검토 후 확정한다"고 명시하고 있다.
본 문서는 그 절차대로 (1) 실제 데이터 분포를 먼저 산출하고, (2) 정책 기준(법령 취지)을
검토한 뒤, (3) 임계값을 확정한 근거를 기록한다.

**(P2 Task 4.5 갱신)** 원천 도서관 데이터(전국도서관표준데이터_인천, 296건) 중 좌표
결측 68건을 `scripts/reading_module/geocode_missing_libraries.py`로 지오코딩(최초
Nominatim 단독 실행: 44건 해결, 24건 미해결)해 `data_processed/libraries.csv`에
반영한 뒤 `build_library_layer.py`·`apply_reading_gap_types.py`를 재실행했다.

**(P5 Kakao 정밀화 갱신)** Kakao 로컬 API REST 키를 확보해 지오코딩 우선순위를
Kakao 주소검색 → Kakao 키워드검색(도서관명+구/군, 결과 주소에 대상 구/군명이
포함된 결과만 채택) → Nominatim(기존 로직) 순 캐스케이드로 재구성하고, 68건 전체를
재지오코딩했다. 그 결과 67건이 해결(전원 `geocode_source=kakao_address`)되고 1건
(자월도서관, 인천광역시 옹진군 자월면 자원리 1116-2)만 미해결로 남았다 — 이 1건은
Kakao 주소검색·키워드검색, Nominatim(원본·단순화 주소) 모두 결과가 없거나(0건)
읍·면 중심점 수준의 근사치만 반환해 건물 단위 좌표를 확보하지 못했다.

이 과정에서 인천 bbox(위도 37.0~37.9, 경도 126.1~126.9)가 옹진군 서해 최북단 도서
(백령도·대청도·연평도)의 실제 좌표보다 좁게 설정되어 있던 것을 발견했다: Kakao가
반환한 이 3개 도서관의 정확한 좌표(예: 백령도서관 lat 37.9704, lon 124.7197)가
기존 bbox 밖으로 판정되어 오탈락하고 있었다. 이는 원본 데이터가 명시한 "인천광역시
옹진군 OO면" 주소에 대해 Kakao 공식 주소 DB가 반환한 검증 가능한 실제 좌표를 배제하는
것이므로, 해당 3개 면(백령면·대청면·연평면, 소청면 포함)에 한해 확장 bbox(위도
37.0~38.05, 경도 124.4~126.9)를 적용하도록 검증 로직을 수정했다(스크립트 주석·docstring
참조). 그 외 옹진군 도서(자월·영흥·덕적·북도면)는 육지에 더 가까워 기존 bbox 그대로
유지한다.

지오코딩 좌표 67건(이전 44건에서 23건 순증)은 참고용 보조 정보가 아니라 등시선 교차
판정에 그대로 투입되어 `external_shortage` 결과에 직접 영향을 준다. 흥미롭게도 결과는
245개교(Nominatim 단독 기준)에서 249개교(Kakao 정밀화 기준)로 **증가**했다 — 직관과
반대로 보이지만, Kakao 좌표가 Nominatim보다 훨씬 정밀하기 때문이다: 이전에 Nominatim이
해결했던 44건 중 22건의 좌표가 Kakao 좌표와 100m 이상 차이 나고(최대 4.5km, 별똥별
어린이도서관), 그중 일부는 부정확한 Nominatim 좌표가 우연히 인근 학교의 500m 등시선과
교차해 `external_shortage=False`로 잘못 판정되고 있었다. Kakao의 정밀 주소 좌표로
교체되면서 이런 우연한 교차가 사라지고 실제 격차가 드러난 경우가 있다. 즉
`external_shortage`가 245→249로 늘어난 것은 데이터 오류가 아니라 좌표 정밀도 개선의
결과다. 원본 좌표만 사용했다면(지오코딩 전혀 없이) 253개교가 `external_shortage`였을
것이므로, Kakao 정밀화 이후에도 여전히 원본 대비 4개교가 개선(True→False)되어 있다.
남은 미해결 1건(자월도서관)은 `iso_public_library_count` 계산에서 제외되므로,
`external_shortage=249`는 이 1건이 해결될 경우 근소하게(최대 1개교) 더 줄어들 수 있는
**근사 상한값**이다 — 이전(245, 상한 오차 최대 24개교)보다 훨씬 좁혀진 근사치다.

## 2. 임계값 확정 (Step 2)

### 2-1. `external_shortage` = `iso_public_library_count == 0`

- 채택: 브리프 기본안 그대로.
- 근거: 이 프로젝트의 핵심 원칙(직선거리 대신 실제 도보 500m 등시선 교차)을 그대로
  따르되, 도서관 유형을 공공·어린이도서관으로 한정한다. 작은도서관은 운영 주체·규모·
  개방시간이 균질하지 않아(자원봉사 운영, 비상시 개방 여부 상이) 정책적으로 "충족"으로
  간주하기 어렵다는 판단이며, 이는 앱의 다른 접근성 지표(공원 등)에서도 유지해 온 보수적
  기준과 일관된다.
- 분포 근거: 249/272(91.5%)교가 해당 — "데이터 분포와 정책기준 검토 후 확정한다"는
  제출 문서 문구에 따라 분포를 확인한 결과 절대다수가 외부 결핍 상태이므로, 이 지표
  단독으로는 유형을 가르지 못하고 `internal_shortage`·`demand_high`와의 조합이 실질적
  분기 기준이 된다(아래 3절 분포 참조).

### 2-2. `internal_shortage` = `사서합계 == 0` **또는** `인당장서수 < 인당장서수 중앙값 × 0.5`

- 채택 값: 인당장서수 결핍선 = **24.55권** (매칭 271개교 중앙값 49.1권의 50%)
- 근거 1 (법령 취지 인용): 「학교도서관진흥법」 제12조의 공식 조 제목은 "전담부서의
  설치 등"이며(사서교사 등 배치만을 표제로 삼은 조문이 아님에 유의), 그중 **제2항**이
  "학교도서관에는 사서교사·실기교사나 사서(사서교사 등)를 둔다"고 정하고, **제3항**은
  사서교사 등의 정원·배치기준·업무범위를 대통령령(시행령)으로 정하도록 위임한다.
  2018년 개정 전에는 "둘 수 있다"(임의규정)였으나 2018년 8월 시행 개정으로 "둔다"
  (의무규정)로 바뀌었다. 같은 법 시행령은 이 위임에 따라 학교 규모에 따른 전담인력
  배치 기준을 두고 있다. 이는 학교도서관이 사서 등 전담인력 없이 방치되어서는 안 된다는
  입법 취지를 담고 있으며, 매칭 271개교 중 **93개교(34.3%)가 사서합계 0명**으로 이
  배치 취지에 명백히 미달한다. 따라서 `사서합계 == 0`을 내부 결핍의 1차 조건으로
  채택한다.
- 근거 2 (분포 기반 보조 기준): 사서 배치 여부만으로는 "장서는 충분하나 사서만 없는 학교"와
  "장서·사서 모두 부족한 학교"를 구분하지 못하므로, 브리프 기본안대로 인당장서수가
  인천 초등 중앙값(49.1권)의 50%에 못 미치는 경우도 결핍으로 판정한다. 50%라는 배수는
  "중앙값 대비 뚜렷이 낮은 수준"을 포착하기 위한 통상적 절반 기준이며, 분포상
  25%(32.2권)보다 낮은 24.55권을 컷오프로 사용해 사분위 25%~50% 구간의 학교까지
  과도하게 결핍으로 분류하지 않도록 완충한다.
- 두 조건을 OR로 결합한 이유: 사서 미배치와 장서 부족은 서로 다른 유형의 결핍(인력 vs
  자원)이며 어느 한쪽만 심각해도 독서교육 여건이 취약하다고 보는 것이 정책적으로
  타당하다.
- 매칭 271개교 중 `internal_shortage == True`(OR 조건 합집합): **123개교**
  — 사서합계==0 93개교 + 인당장서수<24.55권 47개교 − 두 조건 동시 해당(중복) 17개교
  = 93 + 47 − 17 = **123개교**. (참고: 이 123개교 중 `external_shortage`도 True인
  113개교가 `direct_investment_first`로 분류된다. 113은 외부∧내부 교집합이지 이
  internal_shortage 단독 합집합이 아니므로 혼동 주의. `internal_shortage`는 KESS
  데이터 기반이라 지오코딩 정밀화와 무관하게 123개교로 불변이며, 113은
  `external_shortage`가 245→249로 늘면서 111에서 2개교 증가한 값이다.)

### 2-3. `demand_high` = 미래수요 지표 상위 25%

- 사용한 수요 컬럼: **`school_enrollment_forecast_20260418_model1.csv`의
  `forecast_2029`**(2029년 예측 학생수). `학교ID` 기준 조인 시 272개교 전원 매칭 성공
  (결측 0건, 매칭 실패 학교 `인천신검단초등학교`도 forecast 데이터는 존재 — 신설교라
  KESS 학교도서관현황에는 없으나 학생수 예측 모델에는 포함됨).
  같은 파일의 `predicted_2029` 컬럼과 값이 사실상 동일(최대 차이 0.34명)하여 결과에
  영향 없음을 확인 후 `forecast_2029`를 대표값으로 채택.
  브리프 지시("예측 수요 사용, 불가하면 학생수")에 따라 학생수 폴백은 사용하지 않음
  (조인 100% 성공).
- 컷오프: 상위 25% = `forecast_2029 >= 550.25명`(75th percentile). 정확히
  272 × 0.25 = 68개교가 해당(경계값 포함 68개교, 경계 초과만 따져도 동일하게 68개교로
  동률 없음 확인).
- 근거: 2025년 현재 학생수가 아닌 향후 예측치를 쓰는 이유는, 독서환경 투자는 즉시
  집행되지 않고 수년에 걸쳐 이뤄지므로 현재 학생수보다 가까운 미래(4년 후)의 수요
  변화를 반영하는 것이 정책적으로 더 적절하기 때문이다. 인천은 지역 전반적으로 학령인구
  감소 추세이므로, 이 지표는 "수요가 늘어나는 학교"보다는 "감소 폭이 상대적으로 작아
  향후에도 학생 규모가 큰 학교"를 상위 25%로 포착하는 성격을 가진다는 점을 해석상
  유의해야 한다.

## 3. 분기 적용 및 edge case 해석 (Step 3)

Global Constraints의 4유형 매핑을 그대로 사용:

| external_shortage | internal_shortage | demand_high | → reading_gap_type |
|---|---|---|---|
| True | True | True | `direct_investment_first` |
| True | True | False | `direct_investment_first` (edge case, 아래 참조) |
| True | False | — | `school_hub_mobile` |
| False | True | — | `public_link` |
| False | False | — | `maintain_monitor` |

### Edge case: 외부·내부 모두 부족하지만 수요가 상위 25%가 아닌 경우

제출 문서 원문은 "외부·내부 모두 부족하고 미래수요가 높은 경우 직접투자 우선"이라고만
명시하며, 외부·내부 모두 부족하지만 수요가 낮은 경우는 문서에 별도 분기가 정의돼 있지
않다. 본 구현에서는 다음과 같이 해석한다.

- **결정**: `direct_investment_first`로 분류하되, `reading_gap_reason`에
  `demand_high=False`임과 "수요충족군보다 후순위" 취지를 명시적으로 기록한다.
- **해석 근거**: 외부·내부 모두 결핍이면 그 자체로 독서환경이 가장 취약한 상태이므로
  투자 방향(직접투자)이 바뀔 이유는 없다. "미래수요가 높은 경우"라는 조건은 4유형을
  가르는 분기 조건이 아니라, 같은 `direct_investment_first` 유형 내에서 "최우선"과
  "후순위"를 구분하는 우선순위 조건으로 해석하는 것이 문서 취지("직접투자 우선")에
  더 부합한다고 판단했다. 즉 direct_investment_first를 두 개의 별도 유형으로 쪼개지
  않고(브리프의 4유형 계약 유지), reason 문자열로 우선순위 차이를 구분한다.
- **영향 범위**: 매칭 271개교 중 외부·내부 모두 부족(113개교) 가운데 66개교가 이
  edge case(수요 상위 25% 아님)에 해당하고, 47개교는 수요도 상위 25%(정상 케이스)에
  해당한다.

### 매칭 실패 학교(1건) 처리

`인천신검단초등학교`(학교ID `B000026471`)는 KESS 학교도서관현황 2025 원천에 레코드가
없어(Task 1에서 확인된 신설교 추정) 사서합계·인당장서수 등 내부 지표를 산출할 수 없다.
계약 규칙("미확보 항목은 `추가 확인 필요`로 표기")에 따라:

- `internal_shortage` = `"추가 확인 필요"` (bool 아님)
- `reading_gap_type` = `"추가 확인 필요"`
- `reading_gap_reason`에 사유(KESS 레코드 없음)와, 산출 가능했던 부분 정보
  (external_shortage=True, demand_high=False)를 함께 기록해 향후 KESS 데이터 보완 시
  재분류할 수 있도록 함.
- `external_shortage`·`demand_high`는 KESS와 무관한 지표(등시선 교차, 학생수 예측)이므로
  정상 산출해 컬럼에 값을 채움(내부 지표만 결측).
